# 致動元件共同安裝流程

## 目標與範圍（2026-10-20）

第一個垂直案例：MG995 外殼裝在機架桿，輸出軸帶動另一根桿。TT 共用旋轉致動安裝；針筒沿用現有純候選規劃及固定軸求解，調整為相同四步與固定面位置。流程：承載零件與面 → 軸心位置與方向 → 輸出零件與孔 → 試動確認。手機上半部保留模型，下半部獨立捲動。

旋轉輸入使用既有 bar／gear、physicalMotor、motorCarrier、phaseOffset 與 motorMount，不新增求解器。候選不改正式作品，確認整筆 undo／保存；舊作品無新欄位時保留原行為。motorMount.face 選配 front/back，未提供仍用原背面呈現。選定實際承載桿時，沿用 motorMountPoint 安裝孔特徵與 frameSeparate 板件，不將輸出孔誤稱固定螺絲孔。

軸心位置先支援既有端孔。未連接的單根輸出桿可平移對孔；已連接的機構不能偷偷拉斷接點或移動整組，必須使用共同接點。舊有世界機架保留為明確的「自動機架」選項。活動承載桿使用既有相對角度求解；齒輪固定在活動承載桿與針筒隨動外殼目前不宣稱支援。

## 驗收

- 實際零件／端孔、固定面與方向可選，模型同步標示兩側用途。
- 新增與修改候選取消不改作品；確認一次復原；存檔重開保留面與承載／輸出關係。
- 旋轉試動重用 compileTopology／solveTopology，無法求解有原因且不能提交；五金、扭力、干涉未驗證明示。
- 正背面在 3D 的馬達本體、軸與輸出層一致，舊檔預設不變。
- 舵機／TT、針筒原安裝與試動回歸，桌機與 390×844、矮手機驗收。

## 已完成與限制（2026.10.20.12）

- TT／MG995 新增入口、齒面首次安裝入口共用候選安裝；既有致動元件直接開第 4 步摘要，可切換任何設定步驟。更換輸出保留原馬達編號，候選清除舊輸出驅動，不複製第二顆馬達。
- 明確選定承載桿後保留其實體板件（frameSeparate）及安裝孔宿主（motorMountPoint）。正面安裝的輸出桿置於承載板背側，馬達本體在正側、軸向為 −Z；背面相反。舊檔沒有 face 時完全沿原配置。3D 重用鍵包含面與軸向，避免切面後重用錯誤外形。
- 本輪實際承載零件為兩孔桿，軸心位置為端孔；輸出支援兩孔桿與齒輪主動輪。任意板面位置、三點板承載、活動承載齒輪與針筒隨動外殼不在本輪求解能力內。自動機架僅沿用背面安裝；正面需選實際承載零件。
- 不重構舊馬達域、不改示範機構尺寸、不以預覽代替五金／軸長／干涉／扭力驗證。安裝示意的軸長仍是幾何橋接，非實際零件選型。
- 18 組定向 Node 驗收通過；瀏覽器旋轉致動 19 項、液壓 45 項通過。390×844、360×640 手機檢查預覽、選項捲動及固定底列；3D 初次斜視，保留模型旋轉操作。
