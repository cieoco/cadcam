# SDD — 雷射板材榫槽＋螺母鎖固接合（3 mm／M3）

日期：2026-10-24（Asia/Taipei）

版本：試作 v0.2，對應應用程式 2026.10.24.3。**軟體功能與名義尺寸試片已實作；材料、雷射切縫與實物驗證仍待試切。**

需求來源：使用者確認要用板材 T 形螺母卡槽固定垂直板件，先採 3 mm 板材與 3 mm 螺絲。本案將後者解讀為 **M3 公制機械螺絲的公稱直徑**，不是長度或通孔直徑。

上位契約：[共同操作](SDD-WORKSPACE-OPERATIONS.md)、[框架穩定化](SDD-FRAMEWORK-STABILIZATION-2026-10-09.md)、[接合面](SDD-MATE-FACES.md)、[Blocks／教學方向](SDD-BLOCKS-AI-TEACHING.md)。歷史文件中的全部行程、加工就緒等說法，不擴大本案驗證範圍。

## 1. 這次要解決什麼

目前直角接合主要利用角碼及板件固定孔。新增「榫槽＋螺母鎖固」選擇：底板與立板仍由雷射切割，兩個凸榫插入配對長槽定位，中間的 M3 螺絲穿過底板，鎖進立板 T 形槽內的螺母。保留拆裝能力，免用該處的角碼。

成功的第一個案例是：**一片 3 mm 立板垂直接到一片 3 mm 底板，畫面、兩片切割輪廓、五金清單與實際裝配方向相符。** 不是完成整台機構，也不由「畫面接上了」推定強度足夠。

### 已確定、暫定、待量測

| 類別 | 內容 |
| --- | --- |
| 使用者已確定 | 垂直板件固定；雷射加工板材；公稱板厚 3 mm；M3 螺絲與螺母 |
| 本草案試作選擇 | 90°、立板直邊接底板大面；兩個矩形定位榫＋一組中央螺絲／螺母；一般 M3 六角螺母；非沉頭螺絲＋頭下平墊片 |
| 尚未確認 | 材質、兩片實際厚度、螺母及墊片實物規格、雷射切縫、鬆緊配合、工具空間、使用負載 |
| 必須實作後才知道 | 學生能否順利放入螺母、3 mm 板是否易裂、試片的定位晃動與重複拆裝結果 |

暫定項可依試片修訂，記錄原因及受影響測試，不要求使用者動工前回答所有尺寸問題。

## 2. 第一版範圍與操作

- 沿用現有組立接合精靈、選零件／選面與候選確認流程，不另開一套組立工具。
- 在接合方式加入「榫槽鎖固（M3）」，與角碼互斥；切換只改候選，確認後才替換同一接合的加工特徵與五金。
- 支援平面板材上有足夠留料的**直線板邊對大面**；幾何必須能定位到真實板邊，不能把包圍盒六面當成切割邊。
- 第一個 fixture 使用兩片明確的矩形板；正式 UI 只開放能通過同一幾何條件的既有固定板件。P0 必須確認現有板件表示及接合參照能承載此 fixture；若缺能力，先列最小缺口，不另建通用 CAD。
- 一筆接合採一組雙榫／單螺絲；沿用現有單一宿主的組立樹，不新增閉合多重約束。多筆接合仍須檢查加工特徵互相衝突。
- 機架的參數化外框、融合件、曲邊、齒形邊、薄桿空間不足、活動鉸接與非 90° 均不在首例支援範圍；給具體原因並可選回角碼，不偷偷改板寬或換接合邊。

學生預設只看：接合方式、放置位置／方向、3D 預覽及確認。沿接合邊移動整組榫槽，只有唯一合法位置才預選；有歧義時選取，不代猜。板厚不符時明示實際厚度；不得為使用本預設而靜默把 4 mm 改成 3 mm。

進階製作區才提供實測厚度、榫槽配合、螺母／墊片規格與螺絲長度等。利用現有「製作設定」，本案不另建全站老師模式。手機保持至少 44 CSS px 主要點選區；錯誤直接顯示，詳細尺寸可展開。

不做：螺紋攻牙、沉頭孔／盲孔、CNC 刀具轉角補償、任意角度接頭、自動負載計算、摩擦／破壞模擬、以螺母卡槽替代所有角碼、雷射機控制或刀路下發。

## 3. 接頭構造與幾何定義

採局部座標：`u` 沿接合邊，`v` 沿立板向上，`n` 沿立板厚度方向。底板上表面為 `v=0`，下表面 `v=-tHost`；立板肩部貼在 `v=0`，凸榫向負 v 插入。螺絲由底板下側沿正 v 鎖入，螺母軸也沿 v。

```text
立板正視（u–v 平面，未按比例）
          │  螺絲末端避空  │
       ┌──┴───────────┴──┐
       │    螺母橫向卡槽    │  ← 螺母軸沿 v，不是平放在板面
       └────┐      ┌─────┘
            │ 螺絲槽 │
肩部 ───┐ ┌─┘      └─┐ ┌───  v=0
        │ │           │ │
        └─┘           └─┘       兩個凸榫

底板俯視：  [插槽]      ○      [插槽]
                       ↑
                  螺絲穿過的圓孔
```

1. 雙榫與肩部定位並限制繞螺絲軸轉動；螺絲提供夾緊。不能以一個圓孔配一顆螺絲宣稱完整定位。
2. 卡槽在立板平面內的橫向尺寸對應螺母的對邊尺寸，沿螺絲軸的尺寸對應螺母厚度。不是把六角外形直接畫成平放六角孔。
3. 六角螺母在 3 mm 板的兩側會突出；3D、空間檢查和裝配提示須包含實際六角包絡。卡槽限制轉動，不保證未鎖緊前不會從板側掉出。
4. 螺母從立板側面放入，螺絲從底板下方穿入；兩條裝入路徑與工具接近方向都必須顯示。第一版不使用膠或壓配來假定螺母預先固定。
5. 凸榫／配對槽與中央孔共享同一組局部基準，切換姿態只做剛體變換。孔距及原機構接點不因加工外形而改動。

### 3.1 可重現的幾何試作種子

以下是**軟體 fixture 與試片的起始設計值，不是已通過的施工規格**。所有配合量指「總尺寸差」，不是單側差；實測厚度可在公稱 3 mm 的試片中覆寫。

| 參數 | 種子／規則 | 依據與限制 |
| --- | --- | --- |
| 底板／立板公稱厚度 | 各 3.0 mm | 使用者指定；實測分別保存，不能只用全域板厚 |
| 試片底板 | 60×40 mm | 本案 fixture，接頭置中 |
| 試片立板 | 肩部以上 40×30 mm | 本案 fixture；厚度沿 n |
| 榫數／榫寬／中心 | 2；各 8 mm；u=−12、+12 mm | 試作值；整組需真實邊長及留料空間 |
| 榫長 | `tHost`，名義齊底板下表面 | 不以延長螺絲替代凸榫長度設定 |
| 插槽 u 長度 | 榫寬＋0.15 mm＝8.15 mm | 起始總間隙；試片後修訂 |
| 插槽 n 寬度 | `tChild`＋0.15 mm＝3.15 mm | 起始總間隙；本版槽長與槽寬共用 slotClearanceMm |
| 螺絲 | M3，粗牙螺距參考 0.5 mm | 商品規格須核對，M3 不等於通孔 3.0 mm |
| 頭下墊片厚度 | 0.5 mm | fixture 假設，外徑及實物尺寸待核對 |
| 中央通孔／螺絲槽寬 | 3.4 mm | 本案起始間隙值，不宣稱是指定加工標準 |
| 六角螺母對邊／軸向厚度 | 5.5／2.4 mm | M3 DIN 934 商品參考；不含法蘭或防鬆螺母 |
| 螺母槽寬／軸向高度 | 5.7／2.6 mm | 分別加 0.2 mm 總間隙；不能由「3 mm 板」推導螺母尺寸 |
| 螺母槽中心 | u=0，v=6 mm | 先以槽中心定位，裝配夾緊時需考慮槽內軸向游隙 |
| 最小剩餘料寬 | 3 mm 起始檢查值 | 是本案幾何篩檢門檻，並非強度保證 |
| 螺絲長度候選 | 先檢查 M3×12 mm | 須經實際堆疊及末端避空判斷，不寫死為永遠可用 |
| 螺絲末端避空 | 候選長度計算後額外留 1 mm | 與中央槽／螺母槽布林聯集，形成單一切割邊界 |

一般六角螺母的對角包絡不得直接當成 5.5 mm；以所選實物或經驗證的六角幾何建立 3D。其突出會影響鄰板與工具空間，不能因板件本體不相交就通過五金檢查。

### 3.2 螺絲長度判定

令 `a` 為肩部到螺母近端的軸向距離、`hNut` 為螺母厚度、`w` 為頭下墊片厚度、`p` 為要求露出量，從螺絲頭下量起：

`Lmin = tHost + w + a + hNut + p`

- 試作先要求螺絲穿滿一般螺母並露出至少一牙（參考 p=0.5 mm），不是承載設計認證；按槽游隙的最不利螺母位置計算。
- 螺絲末端位於 `vTip = L − tHost − w`，其槽需延伸到該值之外；同時保留到板外緣／其他孔的最小料寬。
- 種子中心 v=6、hNut=2.4、槽高2.6 時，最遠螺母端約 v=7.3；Lmin 約 11.3 mm，12 mm 可作候選，但仍須驗證頭部、墊片外徑與裝入空間。
- 若選取長度太短／太長、部分牙螺絲的無牙段進入螺母、工具空間不足，給具體錯誤；不只依螺絲名稱認定可安裝。

## 4. 雷射加工與試片契約

- 先生成**目標成品輪廓**：外框、凸榫、插槽、螺絲孔、開口 T 槽；所有特徵為貫穿切割，保持 mm、1:1。
- 第一版 SVG／DXF 不自動加雷射切縫偏移。清楚標示「未做切縫補償；依實測於加工軟體補償一次」。現有 CNC 刀徑不能代替雷射切縫。
- 間隙是裝配要求，切縫是製程移除量，分開記錄；不得在尺寸與加工軟體同時補償。切縫未知時僅提供標為待校正的試片設計，不宣稱正式加工就緒。
- 螺絲槽＋螺母槽＋末端避空相交是預期的聯集；位於板邊的開口必須合入外輪廓。不得輸出重複線、開放輪廓、零寬橋接或自相交。
- 產生至少三組試片配合量（總差 0.05／0.15／0.25 mm 作探索起點），逐組標示材料批次、實測厚度、補償設定與結果；不把這些數值當成不同機台的通用建議。
- 先量測／試切再選預設。測試包含手動插入、肩部貼合、螺母裝入與不空轉、螺絲到底、拆裝後裂損及晃動。材質未定時保留為待驗證，不自動代選夾板或壓克力。
- 檢查通過的輪廓可輸出作試切；帶幾何錯誤的受影響零件禁止輸出。不因刪除診斷或略過無效接合而輸出缺少榫槽的普通板。

原 `face-mount-contract.js` 只接受 face.version=1。試作新增 v2 與嚴格 fastener 檢查；舊角碼仍使用 v1。

### 5.1 資料契約與相容門檻

- 新接合採 `mount.face.version=2`（僅新接法），在 `selection.fastener` 保存 `{kind:'tab-nut-m3', version:1, ...}`；既有 face v1／orient／planar 保持讀取與既有語意。具體欄位在 P0 對齊，P1 以往返 fixture 固定。
- 新型別至少保存：host／child 明確零件參照、真實邊參照、沿邊位置與方向、各板公稱與實測厚度來源、榫寬／間距／配合量、螺母槽位置與間隙、五金規格快照、未補償的輸出約定及參數版本。
- 避免只保存會因外框重算而變動的線段序號；邊參照須可驗證，失效時要求重選，不默默跳到最近的一條邊。若首例無穩定邊身分，P0 先解決，不用世界座標硬黏。
- 保存參數而非把派生孔槽永久混進原板件。重新讀檔、修改尺寸、換邊與接法都重算；卸除接合只撤掉該接合的特徵，不刪使用者本來的孔。
- `brackets` 與新 fastener 不能同時存在於同一接合；遇到矛盾、未知型別或版本，當前版本必須明確報錯，不當成角碼／無固定件繼續輸出。
- 新讀取器向後相容舊作品；**不承諾舊網站版本可讀新接法**。新檔需標示最低功能版本；既有舊讀取器可能拒絕 face v2 並解除 mount，僅加標記不能保證它安全處理。發布與分享必須指向支援新格式的版本，跨版本測試記錄實際結果。
- 根 snapshot 是否需要提高版本或加入強制能力檢查，P0 以「不能把新接法靜默降為可加工普通板」為門檻決定；沒有完成此讀取／輸出錯誤路徑前不發布新作品產生入口。

### 5.2 共用幾何計畫

計畫輸出至少包含：接合 ID、來源 revision、兩端部件／局部座標基準、原外框加減特徵、規劃後輪廓、螺絲／螺母／墊片姿態及 BOM、工具與裝入空間、帶對象的診斷、驗證覆蓋狀態。

- UI 只把計畫畫出來，不另算一套孔位；設計輪廓、3D、SVG、DXF 與製作包必須使用相同結果。
- 生成特徵 ID 含接合身分／零件身分，避免同板多接合互相覆蓋；兩筆特徵重疊或薄弱留料不可當成一般孔合併。
- 本案不改運動求解器：接頭沿用固定剛體關係；板件加工外形不得改變原機構孔距與運動參數。
- 確認時核對來源 revision；過期預覽必須重算。取消不改作品／undo／自動存檔；確認含兩板特徵與五金，為一筆可完整復原的操作。

## 6. 驗證規則與可見回饋

分別記錄「幾何已驗證」「製作資料已核對」「實物試片已測」；尚未覆蓋的負載、振動與全行程干涉保持未驗證。

| 檢查 | 失敗回饋例 | 結果 |
| --- | --- | --- |
| 板邊對大面、90°、零間隙肩部貼合 | 此接法需要直板邊垂直接到板面 | 不可確認此接法 |
| 厚度、孔槽及五金參數有效 | 請先核對兩片板厚／螺母尺寸 | 可看概念；不能標製作資料已核對 |
| 凸榫與插槽逐一配對、方向及長度一致 | 定位榫超出底板或無配對槽 | 禁止確認／受影響件輸出 |
| 孔槽落在可加工區、保留料寬 | 螺母槽距離既有孔太近 | 禁止確認／受影響件輸出 |
| 機構孔與既有加工特徵 | 接頭會切到樞軸孔 | 不自動移孔／擴板 |
| 螺絲軸與螺母同軸、有效長度 | 螺絲太短／末端超出避空 | 提供改長度或位置的原因 |
| 頭、墊片、突出螺母及裝入通道 | 底板下方沒有放入螺絲的空間 | 阻止已檢出碰撞的配置；未能覆蓋者標人工核對 |
| 重新修改板厚／外框／接合位置 | 尺寸已變更，需重新核對接頭 | 作廢舊校驗與試片適用性 |

接觸與碰撞需排除合法肩部貼合、凸榫在配對槽內、螺絲在通孔／螺母內等設計配合；不能關閉整個碰撞檢查來消除預期接觸警告。實際螺紋牙形不做碰撞求解，以明確配合包絡處理。

| ID | 案例與應通過的行為 |

## 8.1 試作實現與驗證邊界

- `tab-nut-geometry.js` 共用純幾何，`tab-nut-plan.js` 對接作品；`tab-nut-hardware.js` 依同一局部基準放置螺絲、頭、墊片與突出螺母。板孔、外框、2D／3D 與輸出共享幾何；沒有更改求解器。
- 唯一真實直邊依 `boundary:front/back/left/right` 語意重新驗證，不保存易變的線段序號。實際板厚讀取各零件 stock；試作允許 2.5–3.5 mm，不替使用者變更板厚。
- 矩形 60×40／40×30 mm 試片由純幾何產生。主工具的「製作：3 mm／M3 榫槽接合」範例則使用既有固定寬桿（圓端），示範真實直邊接合；不為此新增通用矩形 CAD 零件型別。
- 新作品與含此接法的模組庫輸出採 `blocks-envelope`，要求 `tab-nut-m3-v1` 能力，正式 snapshot 放在 `project`。舊讀取器看不到頂層 comps 而拒絕，不會把未知 v2 降成可加工普通板。內部 undo 維持既有 snapshot，普通作品輸出不變。新讀取器拒絕未知版本、矛盾接法與遺失參照。
- 支援同底板多筆互不衝突接合。首版保守拒絕同一立板兩筆外框修改、與角碼／轉接孔混用的板、融合件、自動機架、活動件及不具唯一方向直邊的外形。
- 墊片外徑 7 mm、頭徑 5.5 mm、頭高 3 mm 為試作假設；不是已採購標準。螺絲視為全牙包絡，未建模螺紋；部分牙商品、裝入路徑與工具操作空間須人工核對。材料碰撞僅覆蓋模型已呈現的靜態姿態與五金，不代表完整工具掃掠或負載驗證。
- 參數介面直接提供榫寬、雙榫中心距、插槽總間隙與螺絲長度；沿邊位置、螺母中心位置及螺母／墊片尺寸收在「更多尺寸與五金」。可展開的尺寸圖只讀取已驗證的共用輪廓，不另造加工模型。榫長自動跟隨承接板實際厚度，配對槽尺寸同步顯示；輸入時預覽草稿，清空／無效或尚待驗證時不能確認。槽長／槽寬暫共用一個總間隙，螺母另有總間隙；雷射切縫不自動補償。
- 試片下載固定使用 3 mm 名義厚度與三組間隙，不跟隨目前作品參數。每列左底板／右立板；圖面 y=25、80、135 mm 分別為 0.05、0.15、0.25 mm。試切前在加工軟體依量測修改厚度配合及補償一次。
