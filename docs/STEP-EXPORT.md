# 匯出 STEP（專案 → 匯出 STEP）

把作品裡的板件存成 STEP（ISO 10303-21，AP214 `AUTOMOTIVE_DESIGN`）實體，Solid Edge、Fusion 360、FreeCAD 等 CAD 直接開啟。程式在 `js/blocks/step-export.js`，自己寫的小寫入器，不用 WASM 或 CAD 核心；按下按鈕才載入，不在啟動載入圖內（`test/startup-size.mjs` 檢查）。測試 `test/step-export.mjs`；外部驗證 `tools/step-verify.py`（OpenCascade）。

## 匯出什麼

- **設計模式**：目前這個設計（焦點分頁）的板件。裝在別的機構上的設計，形狀（含接合的榫槽、孔）照組立，位置改放在它自己的平面上。
- **組立模式**：整個組立（機器）在目前姿態的位置；驅動角、各馬達角、針筒伸出量都照畫面現況。
- 板件＝連桿、三角板與連接板、齒輪與齒條、機架板與各機構的底板、卡榫盒子的各片板。形狀、孔、挖空、板厚、疊放高度與 3D 預覽用同一份材料場景，所以看到的就是匯出的。

每片板是一個零件（PRODUCT），名稱保留中文（檔案只含 ASCII，中文用 `\X2\…\X0\` 編碼，CAD 讀回來是中文）。檔案裡有一個以作品名為名的組立，各零件帶自己的位置；零件本身畫在自己的座標（外形在 XY 平面、厚度沿 +Z，z＝0…板厚），要拿去畫工程圖或轉 DXF 很方便。

每片板的實體（MANIFOLD_SOLID_BREP）：

| 面 | 型式 |
|---|---|
| 上、下面 | 平面；外迴圈＋每個孔與挖空一個內迴圈 |
| 直線外形邊、挖空邊 | 平面側面 |
| 圓孔 | 真正的圓柱面（`CYLINDRICAL_SURFACE`，圓邊是 `CIRCLE`，接縫一條直線邊） |

曲線外形（齒輪、凸輪外形、圓角機架）在上游已是折線，這裡就是一段一段的平面；圓孔不被折線化。孔彼此重疊或落在挖空裡時先合併成一個挖空（那一個變成多邊形）。單位 mm；同樣的輸入產生逐字相同的檔案（沒有時間戳）。

## 不匯出什麼

買的零件這一版不匯出，完成時的提示與 `skipped` 會列出名稱：

- 馬達、伺服（TT、MG995、N20）、針筒、滑軌、凸輪、皮帶輪與鏈輪（買現成）、皮帶與鏈條、工件
- 螺絲、螺母、墊片、角碼翼片（以「螺絲 ×6」這樣的數量列出）

孔或挖空碰到外形邊、或超出外形（上游設計本身就不成立）時不寫進實體，並在提示的「注意」裡說明。這種板在 CAD 裡會比畫面少幾個孔。

## 在 CAD 裡開啟

- **Solid Edge**：檔案 → 開啟，選「STEP (*.stp, *.step)」。檔案是組立，開啟後零件樹是作品名底下每片板一個零件；要存成 Solid Edge 檔就整個另存。
- **Fusion 360**：上傳（Upload）或「插入 → 插入 CAD 檔案」，選 `.step`；零件在 Browser 裡是同名的元件。
- 單位是 mm；若 CAD 提示單位，選毫米。板件沒有顏色與材質。

## 姿態矩陣的約定

`stepFromParts(parts, {name, warnings})` 的 `matrix` 是 16 個數字、**欄主序**（與 3D 場景的 `part.pose.matrix`、`applyMatrix4` 相同）：`[ux,uy,uz,0, vx,vy,vz,0, wx,wy,wz,0, tx,ty,tz,1]`，平移在 `[12]`、`[13]`、`[14]`。只取旋轉＋平移，行列式為負（鏡像）會丟錯。

注意：`test/step-export.mjs` 的姿態範例把矩陣寫成「列主序、平移在 `[3]`、`[7]`、`[11]`」，與 app 的欄主序不同。測試只檢查「檔案裡有擺放資訊」，所以兩者都過；那個範例照 app 慣例讀會是原點、只有旋轉。

## 限制

- 只有板件；沒有五金、馬達、針筒，也沒有零件之間的接合（配合）關係，要在 CAD 裡自己配。
- 位置是匯出當下的姿態（單一姿態，不是動畫）；機構在這個姿態無法求解時不匯出。
- 設計模式只匯出目前分頁；整個作品請切到組立。
- 外形有多個分離島的零件，同一個零件裡有多個實體。
- 不帶顏色、材料、公差、工程圖。
- 驗證：`python3 -I tools/step-verify.py a.step`（需要 `pip install cadquery-ocp`）用 OpenCascade 讀檔，檢查每個實體有效、列出實體數、體積與包圍盒；加 `--names` 列出組立樹、`--expect-volume` 比對體積。
- 目前只用 OpenCascade 驗證過（實體有效、體積、位置、中文名稱與組立樹）；尚未在 Solid Edge、Fusion 360 實機開啟確認，第一次使用請先開一個小作品核對。
