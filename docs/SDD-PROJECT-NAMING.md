# 作品與分頁命名第一階段

## 範圍

維持 Blocks v1 JSON 完整作品檔，不增加零件／組立副檔名或外部參照。作品包含所有設計分頁、尺寸及組立關係。

- 存檔開啟頁面內命名視窗，確認才下載；取消不改資料。
- 目前分頁旁的鉛筆按鈕可改名，桌面亦支援雙擊分頁。
- 單一設計改名或存檔時，同步作品與分頁名稱。
- 多分頁時，作品名稱與各分頁名稱獨立；改名不改 module ID、孔 ID 或接合關係。
- 名稱最多 40 字，沿用既有模組上限；檔案不合法字元與分享不允許字元改成底線，自動附加一次 `.json`。
- 保存使用選配 `projectName`、`rootDesignName` 頂層欄位；模組分頁沿用 `modules[].name`。舊檔未命名仍可讀，從檔案開啟時可採原檔名作作品名稱。
- 名稱經 snapshot 保存、自存、分享及復原；純幾何求解不讀這兩個名稱欄位。

## 驗收

`test/project-name.mjs` 覆蓋名稱正規化、JSON／分享往返、任務來源接受名稱與舊檔相容。`test/design-isolation.html` 加入單頁同步、多頁獨立、取消、一次復原及重開驗收。實際下載 `四連桿練習.json`，核對檔案內作品與分頁名稱一致。
