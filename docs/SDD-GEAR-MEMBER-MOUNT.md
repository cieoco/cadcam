# 齒輪與夾指兩孔安裝

日期：2026-11-01。範圍：單一設計中的未固定連桿、三點板及合成連桿，安裝到既有齒輪。

## 問題與完成行為

鏡射副本使用獨立孔 ID，直接重疊不會建立傳動；既有拖孔合併不支援齒輪與合成桿。案例右側夾指孔距 18 mm、齒輪輸出孔距 23 mm，需要使用者選擇對孔與調整孔距。

選零件 → ⋯ → 安裝到齒輪，選目標、夾指軸心孔及定位孔。預覽只平移旋轉整片，不改桿長、夾角或左側零件。孔距不合須勾選調整齒輪孔距；定位孔可明確選擇轉向 180°。確認一次寫入與復原，取消不寫入，舊預覽遇到作品變更須拒絕提交。

## 設計與限制

- 純規劃模組回傳候選，UI 懶載入；共用點 ID 表示安裝，barFusion 局部形狀不變，僅更新選定的兩個孔 ID。沿用既有 snapshot、正規化、保存、分享與求解器。
- 同步量尺端點、基準與追蹤點；其他零件或模組介面已引用來源時拒絕搬移。動力、固定孔、伸縮桿、盒體及已和齒輪融合的零件不支援此操作。
- 改齒輪孔距或方向可能影響其他輸出，已接外部零件時拒絕；共用孔距參數亦拒絕自動改寫。新孔距沿用齒輪調整的 4 mm 至節圓半徑減 4 mm 範圍，這不是加工安全認證。
- 不新增通用 3D 裝配、任意孔或加工輪廓聯集。齒輪與合成夾指仍分件輸出，五金、板厚、軸配合、層次、干涉與承載須另核對。
