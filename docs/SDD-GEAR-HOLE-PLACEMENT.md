# 齒輪輸出孔起始位置與對稱配對

日期：2026-11-01。目的：讓兩顆等齒數齒輪上的輸出孔對稱，供後續安裝鏡射夾指。先設定孔位，再安裝夾指。

## 操作契約

- 選齒輪 → 更多 → 調整孔位：可拖綠色孔位，也可輸入孔距及起始角度，0°向右、90°向上、180°向左；角度相對設計座標，以所有馬達0°為起始參考。候選預覽不改作品，不改當下播放角度。
- 「與另一齒輪對稱」選來源齒輪，依兩軸的垂直平分線鏡射來源輸出孔。若軸心連線方向為β，目標角度為2β＋180°－來源角度，孔距相同。例如水平並排時30°→150°。畫面橘線是對稱中線。
- 自動配對限同設計、同齒數及節圓、直接嚙合、兩軸固定且中心距正確的齒輪。直向與斜向排列同樣適用；不同齒數不能宣稱對稱開合。
- 確認一次復原與保存；取消不寫入；作品變更後拒絕舊候選。設定已相同時不新增復原。這是一次配對，不保存永久對稱約束，日後更改來源須再次套用。

## 實作邊界

- 沿用phase、pinRadius／pinRadiusParam與p2，不新增存檔格式或第二個輸出孔。純候選計算與DOM視窗分開，介面延後載入。
- 調整目標若輸出孔已共用、已聯集、掛針筒／齒條／承載零件或被模組介面引用，拒絕搬孔，避免把桿長及合成局部形狀拉壞。來源可已有夾指，來源不改。共用孔距參數拒絕單獨改寫。
- SVG／DXF及3D沿用既有齒輪幾何。孔距範圍採4 mm至節圓半徑減4 mm；不宣稱已驗證孔與齒根／舵盤孔的加工間隙、實物干涉、承載或抓取。
