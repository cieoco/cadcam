# SDD — 單軸翻斗教學試點

日期：2026-10-10。狀態：B0–B3 完成；側視教學試點已驗收，尚未發布。

## 目的與範圍

以「收納 → 翻轉 → 回位」學習單軸機構的角度與工作範圍。目標為適合板材與角碼組裝的取放物概念；本輪不宣稱已符合特定 FTC 賽季規則或完成比賽硬體選型。

概念組成為左右支撐板、同軸轉軸、料斗側板／底板及必要連接件。第一輪先建立可對回作品的 **2D 側視運動模型**：固定軸、單一驅動、剛性料斗側形，清楚標示開口方向。側視輪廓不等於完整料斗，也不是已核對的板件展開圖；另一側板、底板、跨寬連接與五金待後續組立規格確認。

## 盤點與重用

- `js/blocks/examples.js` 目前未找到翻斗專用範例；僅新增一個必要範例，不複製夾爪或升降任務。
- 重用 Blocks v1、既有 anchor／bar／triangle 表達固定軸與剛性側形；先以最小 fixture 確認側形與主孔能由原求解器表示，不新增自訂 bucket 求解器。

- 重用 `task-operation-support` 的來源檢查、候選確認、取消與過期處理；重用 `validateMotionRange` 的有限採樣檢查與可信量測 callback。
- 保留夾爪、平行四連桿回歸；不重寫 state、schema、存檔、播放器或輸出架構。

## 第一輪操作契約

僅提供收納角、傾倒角兩項輸入；尺寸先固定成明確標示的教學示例。角度以圖上固定水平參考線為準，圖解標出正方向與開口，不能直接當伺服命令。可用角度區間及預設值由 fixture 驗證後寫入實作規格，不將任意 0–180° 當作硬體能力。

沿用 `operationVersion: 1`、建立／修改任務、候選預覽 → 確認 → 一筆復原。任務角存於既有 params，保留完整作品與分享／重開能力。未知欄位、非有限角度、超出教學範圍、改造後不支援結構均明確拒絕。不得靜默調整角度或刪除零件。

## 驗證與界限

檢查指定起終角及中間採樣的有限解、固定軸不移動、主孔距固定、料斗姿態符合驅動角、精確端點与疑似跳動。包含反向回位與同角度情境；回報失敗角度、零件與原因，保留採樣步距及未驗證清單。

不把超門檻姿態判定成物理碰撞；不模擬顆粒、摩擦、物件掉落或實際傾倒成功。不聲稱已完成板厚疊放、完整干涉、軸承／馬達固定、重心、扭矩、承載或加工就緒。教學中「傾倒姿態」僅表示幾何角度達標。

## 教學流程

1. 看固定軸、料斗開口與角度基準，預測轉動方向。
2. 保持收納角，只修改傾倒角，觀察開口方向與掃過區域。
3. 操作收納、傾倒、回位；比較角度差與旋轉範圍。
4. 輸入超出教學範圍的角度，閱讀原因並修正重驗。
5. 說明「轉到姿態」還缺哪些實物條件，才可證明能把物件倒出。

## B0 決定（原 solver fixture 通過）

三零件：Axis 固定 O(0,0)、Drive 單 M1 的 O–P 80mm、Bucket 剛性三點 O/P/L(-20,40)。左距 √2000mm、對角 √11600mm；polyline vertices 依 L→O→P→(u100,v40) 呈 U 形開口側視（板件外形，不是斗容積）。0°時開口向上；固定 O 向右水平為角度基準，正角逆時針。收納0°、傾倒−100°，允許−120～30°，只是教學任務範圍。fixture 於0/−100/−120/30°有限解且孔距保持。

造形局部點共用既有 plateVertexWorldPoints，motion 驗證逐幀全頂點對距與主孔剛性；只支援合法三主孔＋有限局部造形點（最多6）、無額外孔。額外孔/未知點拒絕，不泛稱全部機件孔。

## 2026-10-10 產品修正：完整幾何料斗／共用UI（優先於上列側視試點）

使用者要求真正立體料斗與MG995，撤除翻斗常駐專用任務卡。B0已以原六面接合與module frameStock證明：左活動側板＋右側／底／背三獨立板模組，開前上，於0／−60／−100°均為原materialScene的四個材料實體，不造裝飾mesh，不改schema/solver。子板採現有底板（frame），因六面安裝端現僅支援frame／固定bar，不擴triangle限制。

B0示例內腔名義82×42×60mm、板厚3mm；圓角不是密封保證。world-space實際外形上下表面角點、法向、六個接觸邊界與跨板相對距驗算通過（1e−6mm）。fixture與證據在output/tipping-bucket/b0-solid。固定Support支架孔與活動O不同ID同座標，motorMount.frameBody明確指向Support，MG995靜態身體與活動輸出分離；只一側支架，不宣稱双支承或完整軸承選型。支架水平固定，無須motorCarrier騎乘語意。

最小施工範圍：同一tipping-bucket範例改用四模組幾何作品；既有2D分頁/板件編輯/共用MG995起終範圍/組立精靈/3D/輸出，移除bucket任務卡與controller掛接，不順便刪除gripper/parallel卡。MG995 servoStart/End是新作品兩角single source，不存bucket角副本，不當硬體PWM。AI純入口沿共用候選確認、取消、過期、undo；保留舊三件作品legacy驗證，新組立需獨立真snapshot→assembly/materialScene採樣、固定軸、四板相對姿態及接觸幾何檢查。旧側視結果不冒充3D已驗證。

接合定位與實際角碼固定分開；本例四板幾何定位，不先聲稱角碼固定已核對。B1负例→纯入口/组立validator；B2共用UI/教材/撤卡；B3定向→全套/graph→桌面/390px操作，重開、輸出、來源不變與舊例回歸。碰撞、承載、摩擦、落料、硬體仍未驗證。

### B1–B3 最終幾何修正與契約（2026.10.10.6）

以下優先於 B0 的82×42內腔草案與原三件側視描述。實際材料驗證抓到原1mm包邊主孔跨輪廓，已改5mm包邊（LeftSide stock.widthMm=10）；六個vertices沿原solver主孔與局部造形，採既有hull外框，避免中段共線主孔被polygon收圓形成迴圈。最終內腔名義90×50×60mm，RightSide90×50、Back60×50、Floor130×100mm、板厚3mm，底板四周固定翼約20mm。圓角非密封。

O(0,0)移至側板高度中段：左右主孔O/P在側邊中段，L(0,20)，局部底角(0,-20)/(80,-20)、頂角(80,20)。固定Support的另一端S(40,0)在軸右側；SupportAxis與O同座標但不同ID，為固定環境孔與活動軸分離，不是兩活動父。MG995 motorMount.frameBody=Support/outputBody=Drive/orientation=horizontal；模型起終角只取Drive.servoStart/servoEnd（整數），不保存另一份bucket角。新立體教學分支−120～0°，預設0→−100；正30°已知會與固定框相交，故不列入本例有效範圍。這不是MG995硬體限位。舊側視三件仍用原−120～30°及legacy診斷。

接合樹 Driver→Floor→RightSide，Back亦接Floor。三組都由既有face candidate/bracket planner產生有效實體角碼與成對孔，不再使用RightSide gap60隔空定位。四片板皆進入材料catalog、snapshot、2D模組編輯與SVG/DXF。固定支架/MG995目前單側，對側軸承與貫穿軸尚待設計；不稱雙支承。
