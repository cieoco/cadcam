# 手機六面體組立精靈（2026.10.07.8）

組立清單選取機構後，預設入口為「六面體精靈」。依序選兩個機構、承接面、安裝面，再用箭頭與尺寸調整對齊，按「接上」保存。旋轉或上下翻轉可露出其他面；直接點模型面，以變色確認選取。

選面步驟只顯示目前要操作的機構。方向外框刻意放大薄板側面，方便手機點選；放置計算仍使用實際板厚與輪廓。已接上的六面接合可重新選面與尺寸；取消或關閉不修改作品。

自由選面保存組立姿態，尚不代表轉接件或固定孔已設計，也不代表跨面干涉已通過驗證。工程接合操作保留於「進階（工程模式）」。
