# 手機六面體組立精靈（2026.10.07.8）

## 接合設定試作（2026.10.07.10）

設計頁合併為「接合設定」入口。點選機構小圖的部位（變藍並同步選單），設定「裝到這裡／用這裡安裝」以及兩個接合面。安裝部位目前限固定桿／底板或兩端固定的桿件，避免把活動桿當作模組固定基準。舊工程接合面工具可由此入口的「進階接合面」開啟。

每個機構保存一組 `faceParts`：receive 指向合法輸出端，attach 為 frame 或合法固定桿 id；receiveFace、attachFace 為六種面之一。組立帶入兩方的設定與完整機構輪廓；按下一步直接細調。六面體保留於「選面輔助」。輪廓預覽是靜態參考示意，齒輪以圓形呈現；不是完整的干涉／加工驗證。

已操作驗證：點工具架變色、保存下面、設定夾爪底板上面、重新整理保留、帶入預覽、直接細調、確認接上。face-mount 驗收 12/12，含設定保存及無效部位清除；原有模組操作與接合幾何檢查通過。下方保留上一版流程說明供查考。

組立清單選取機構後，預設入口為「六面體精靈」。依序選兩個機構、承接面、安裝面，再用箭頭與尺寸調整對齊，按「接上」保存。旋轉或上下翻轉可露出其他面；直接點模型面，以變色確認選取。

選面步驟只顯示目前要操作的機構。方向外框刻意放大薄板側面，方便手機點選；放置計算仍使用實際板厚與輪廓。已接上的六面接合可重新選面與尺寸；取消或關閉不修改作品。

自由選面保存組立姿態，尚不代表轉接件或固定孔已設計，也不代表跨面干涉已通過驗證。工程接合操作保留於「進階（工程模式）」。
