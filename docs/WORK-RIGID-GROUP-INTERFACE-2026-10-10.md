# 剛性群組安裝介面（2026-10-10）

功能版本：2026.10.10.8，隨2026.10.10.9一併交付。本機實作與驗收完成。

## 操作

1. 載入單軸翻斗 → 組立 → 建立剛性群組，命名「料斗」。
2. 選群組 → 獨立為可安裝群組 → 確認。馬達與固定支架留在 Driver；四片料斗板成為獨立接合樹。
3. 拆下並回位 → 確認。回到板件設計姿態，內部角碼接合保留；不保留拆下瞬間的動畫角度，也不自動移到旁邊。
4. 選群組安裝輸出端 → 準備安裝 → 確認。取消不改作品，每次確認各一筆復原。

## 共用契約

`rigid-group-interface.js` 的 `prepareRigidGroupInterface(snapshot, request)` 接收 operationVersion 1、action extract/detach/attach、hostId、groupId；attach 加 target.module/output。返回候選 snapshot 或 issues。UI 與後續 AI 可使用相同純操作；本輪沒有部署 MCP。

沿用 base/output/mount、prepareConnectionWork、既有求解器與材料模型。抽離為獨立多孔板並複製長度參數，避免改料斗尺寸時意外改動馬達桿。支架與活動板共有更多活動連接時拒絕推測。確認前檢查來源是否已改變。

抽離目前限於未安裝宿主、同軸輸入桿帶動的多孔板。安裝只支援同平面輸出端。群組名稱可解散，結構驗證不依賴名稱存在。拆下狀態依既有製作包规则視為未安裝，不宣稱加工就緒。承載、伺服舵盤鎖固、軸承與全行程干涉仍未驗證。
