# 作品／設計／組立共同操作契約

人、教學及未來 AI 共用 Blocks snapshot 與既有操作驗證，不另建求解器。

## 必須先確定的六個邊界

1. **資料與畫面**：關閉分頁僅收起編輯入口；隱藏僅影響可見性；拆下改接合；刪除才移除資料。不可互相代用。
2. **尺寸與姿態**：孔距是已提交尺寸。拖曳、接合與播放不偷偷修改尺寸；改尺寸須明確操作且驗證。
3. **作用範圍**：設計模式只編輯／模擬本頁；組立模式處理跨設計接合。診斷須指出對象及範圍。
4. **提交與復原**：候選不修改正式作品，取消回原狀；確認是一筆完整復原。分頁開關不佔作品 undo。
5. **驗證證據**：結構、目前姿態、指定行程、加工及實物分別判定。相關資料改動使舊結果失效；未覆蓋的檢查列未驗證，不推論通過。
6. **保存與重用**：作品檔包含完整資料及接合，改名不改 ID；未來模組匯入先使用獨立副本，不先建立外部參照。

這些是後續工作的共同契約，不代表本輪新完成全面加工／干涉驗證或 AI 服務。各域仍以既有 SDD 和實測覆蓋為準。

## 本輪：分頁生命週期

- 分頁 × 改成關閉，已安裝子設計也可關閉，不拆接合、不改尺寸、不重寫存檔。
- 目前分頁關閉後切到另一個開啟分頁；最後一頁關閉後回組立台。
- 設計模式分頁列、組立台頂列提供「設計清單」，列出所有設計，可重新開啟。
- 分頁開關為本次工作階段的 UI 狀態，不寫入作品。重開檔案恢復完整入口，閉合分頁不代表作品遺失。
- 「刪除設計」移到清單獨立操作。保留既有接合保護與確認、復原；本輪不增加連帶刪除或自動拆接合。
- 組立台返回設計模式會開啟其焦點設計。既有編輯、選取及播放流程不另建第二套。

## 範例驗收格式

用途 → 輸入／可調參數 → 預期動作 → 反例 → 驗證範圍 → 加工缺口。每次只擴充案例需要的能力。

## 暫不做

新副檔名、外部檔案參照、協同編輯、通用 3D 約束、力學平台、MCP 服務及完整作品關閉／未存檔管理均不在本輪範圍。

## 組立存取與拆下（2026-10-12）

- 開啟＝替換整份作品，不是匯入零件；有作品時先顯示範圍與「先存檔／選擇作品檔／取消」。選檔取消或解析失敗不替換。
- 儲存＝所有設計、未安裝件、尺寸與接合一起下載，沿用單一 JSON，不新增零件／組立副檔名或外部引用。
- 組立清單選取後直接提供拆下；確認視窗列出此組設計。整組拆下只解除對宿主的接合，子件彼此關係保留。
- 底座與含子件項目可解除此組全部接合；深層先拆，全部成功才提交一筆復原，失敗不提交部分結果。
- 拆下不等於刪除或隱藏：設計仍保留，可重新接合。底座仍是底座；真正刪除設計仍經設計清單。
- 不新增「開啟即加入」或獨立零件實例模型。本輪也不提供只移除中間宿主但自動重新接合子件的推論。
