# 教學與操作現況

更新日期：2026-10-15。教程以七個明確任務串接四連桿、滑塊曲柄、齒輪傳動、聯集夾爪、齒條、翻斗與組立，採「示範 → 沿例操作 → 單變量達標 → 動畫交件」，手機關鍵步驟附圖，影片選看。學生自行將動畫繳交 Google Classroom，不使用學習單；2D 可匯出 MP4，第七課組立序列可匯出 3D MP4，液壓 H01／H02／H03 在設計模式可匯出 2D／3D MP4。H01 改為固定筒身＋短連桿單臂入門，舊鉸接作品保留；H02 提供抬臂孔位比較，H03 提供針筒夾具延伸教程，外形參考教師 F3D，末端與交叉臂為同片剛性造形，沒有額外活動夾片。另提供單側活動夾爪與單軸手腕的可調範例及可插入模組，沿用尺寸、舵機角度與組立；不是實物施工規格。既有擺臂進料亦可加入為模組，提供底座基準與取物端，不帶入示範物件。工具已補上手機軸心點選、聯集預覽、匯出範圍與播放前約束檢查；連桿入口預設兩點桿，三角板／折線由箭頭選擇。80 mm 推送器已有錄影前成果檢查與版本化候選截圖腳本，推送器可由檢查結果接續匯出附尺寸、行程結果與版本的影片；其餘六課尚未提供同等成果驗收。第七課已提供六步模擬動作序列，播放前取樣求解，停止與完成回到原姿態；序列可隨作品保存／重開／復原並匯出附六步角度與版本的 MP4。多孔板仍為規劃，未實作。瀏覽器手機尺寸驗收不等同實體手機驗收，模擬取樣亦不代表連續干涉、承載或加工就緒。
