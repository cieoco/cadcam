# 教學與操作現況

更新日期：2026-10-20。教學首頁先介紹機構、固定／輸入／輸出、接點與基本操作，再依序列出七個單元；針筒延伸與自由改造移至單元七之後，不再預設學生從第二單元開始。教程以七個明確任務串接四連桿、滑塊曲柄、齒輪傳動、聯集夾爪、齒條、翻斗與組立，採單元一～七的單一路徑：每課複習既有技能、增加必要知識與操作、實作並自我檢查；首頁「第一次使用」建立畫桿／機架／動力／保存基礎，第一課直接接成缺桿雨刷，第三課自建齒輪並交由第四課畫夾指；點齒面即可安裝／更換 TT 與 MG995，沿用同一輸入輪，換好直接顯示角度，不需先拆馬達再點小孔，第七課複習平行四連桿、接合與自主需求修改。不再維護獨立自學教程；舊頁僅轉回目錄，範例留作對照，手機關鍵步驟附圖，首頁「第一次使用」從空白畫桿到保存附六張操作截圖與編號，第四／六單元共用三點繪製選單圖，影片選看。自學保留 JSON 與影片，Classroom 僅為班級繳交方式；學生自行將動畫繳交 Google Classroom，不使用學習單；2D 可匯出 MP4，第七課組立序列可匯出 3D MP4，液壓 H01／H02／H03 在設計模式可匯出 2D／3D MP4。H01 改為固定筒身＋短連桿單臂入門，舊鉸接作品保留；H02 提供抬臂孔位比較，H03 提供針筒夾具延伸教程，外形參考教師 F3D，末端與交叉臂為同片剛性造形，沒有額外活動夾片。另提供單側活動夾爪與單軸手腕的可調範例及可插入模組，沿用尺寸、舵機角度與組立；不是實物施工規格。既有擺臂進料亦可加入為模組，提供底座基準與取物端，不帶入示範物件。單軸翻斗與升降托斗可整組加入，保留內部接合，另可插入既有 H02／H03／H04 針筒模組，內建庫共十三項；36 個公開入口已有用途及試改提示，練習、手動及完整機構分開驗收。修正環境物件誤報約束不足；液壓 H01–H03 加工輸出仍受既有規格核對限制。液壓頁在原課程中補入自畫三根桿、從零件清單選機架／端孔安裝針筒，以及用自己的設計組成 H05／H06 的操作圖。組立顯示針筒外形與固定桿，H03 已依要求再回復至改成推出夾緊之前的交叉臂版，第三課與圖片同步還原，設計 3D 不再重複顯示固定桿與其自動機架板；固定針筒的雙耳水管夾已補配對機架孔、夾腳承托面與參考螺絲／套筒，實物五金仍待核對；H05／H06 保留既有的推出夾緊組合變體；H05 疊層保留修正；H05／H06 升降總成改為朝上承接頂端夾爪，H06 由下至上為水平底座左右轉、中段圓弧升降、頂端夾取，3D 地面與視角已對齊；直角接合可選擇先定位、不生成角碼孔，維持「已定位，尚未固定」與干涉提示，不代表加工就緒。舊存檔不強制改寫，新範例需重新載入取得修正。工具已補上手機軸心點選與重疊物件選取清單（舵機／齒輪／夾指可分選）、聯集預覽、匯出範圍與播放前約束檢查；連桿入口預設兩點桿，三角板／折線由箭頭選擇；教程目錄新增桿件操作速查，雨刷課的新增、補接與孔距截圖已更新，推送器及夾爪課連到同一操作說明。範例視窗可直接加入對應模組；新增雙側平行四連桿夾爪（−30°～30° 幾何驗證），與旋轉式雙齒輪夾爪分開命名。組立干涉提供定位與回相關設計修改入口。手機直立組立的上下面板各自捲動，至少保留約 48% 工作區給 3D；橫放改用窄側欄。80 mm 推送器已有錄影前成果檢查與版本化候選截圖腳本，推送器可由檢查結果接續匯出附尺寸、行程結果與版本的影片；其餘六課尚未提供同等成果驗收。第七課改為工具架以角碼承接水平朝前的夾爪，未接合時也顯示各模組自身機架；教程附選面、270° 與 −60 mm 偏移的手機操作圖；接合入口先選承接設計及實際零件，自創作品不需預先宣告輸出端；承接支援連桿、板件、齒條，安裝端列出全部零件，底板只標建議，須自行點選確認；活動件高亮並說明尚不支援重設固定基準，不能直接套用。有預設面的範例仍依序確認承接面及安裝面，手機顯示六面按鈕，可返回修改。接合視窗將承接與安裝零件拆成兩步，上方固定預覽、下方選項獨立捲動，導覽固定在底部；可放大預覽，橫放採左右排列。第七課已提供六步模擬動作序列，播放前取樣求解，停止與完成回到原姿態；序列可隨作品保存／重開／復原並匯出附六步角度與版本的 MP4。多孔板仍為規劃，未實作。瀏覽器手機尺寸驗收不等同實體手機驗收，模擬取樣亦不代表連續干涉、承載或加工就緒。
