# 教學與操作現況

2026.11.9.6：針筒安裝改成同一面板的三個問題（① 固定在哪裡、② 推哪個孔、③ 調整試推），在畫布點零件與孔；還會動的零件可在面板內設為不動的底座，確認鈕旁寫出還差什麼，見[三步驟紀錄](TEACHING-CHANGELOG.md#syringe-install-steps)，瀏覽器驗收待完成。2026.11.9.5：針筒雙孔固定可在原畫布拖曳或輸入精確角度，以第一耳孔調向、保持24 mm孔距；候選經確認才改孔，可取消及一次復原。板件輸出包含固定孔，衝突的未使用格孔停用並可恢復；標準板可保留已鑽固定孔，改向與拆除後持續核對。桌機／手機操作、孔位與SVG／DXF已定向驗證。既有桿件、板材、L型件、致動器、範例與組立仍沿原流程；自動機架歷史鑽孔保存、參考固定環改製、完整干涉／承載與實物加工仍有界限。詳細能力狀態見減法SDD，歷次修改及驗收見更新紀錄；部署以對應提交與發布紀錄為準。
