# 教學與操作現況

目前操作採「直接操作＋參數設定」並存，不需切換模式。可修改的孔距、外徑、位置、方向及安裝尺寸沿用同一候選與驗證；拖曳尺寸／角度取整數，參數保留原支援的小數，點選與取消不改原值，接受後可一次復原及保存。2026.11.6.6 補上自動機架中心線新增孔，可拖曳／輸入距基準孔並接回原畫桿流程；孔跟隨基準方向，外框修改不搬孔，仍未支援任意板面偏移孔。2026.11.6.5 補上刪除連桿後的針筒斷接顯示與重新接孔，未接好不能模擬；機架固定軸方向可拖圖或輸入數字，並非整套機構旋轉。2026.11.6.4 修正無解時固定環與配對孔的顯示方向，拖動可看候選孔位；模擬失敗標亮未受約束零件，點選回原編輯／合成入口。2026.11.6.3 補上固定環／馬達的弧形旋轉把手，馬達安裝方向可拖圖或輸入數字，孔位改變仍需確認；活動承載桿繼續帶動馬達外殼。2026.11.6.2 補齊單支點方向數字、主畫布齒輪孔位、針筒伸出量數字與圖上把手、鏈輪中心距把手；刪除被取代的自訂孔位視窗及針筒重複尺寸欄。直桿中間孔保留兩端總長，夾爪連動依真實連接與鏡射幾何辨識。共用孔仍受桿長與機構約束，已連接齒輪孔或從動鏈輪不能任意搬動。針筒／馬達共用工作點軌跡與毫米量測；3D 為預覽及返回 2D 選取入口。建立、鏡射、合成、組立及加工輸出沿用既有流程與確認，板厚沿用製作設定。任意多孔、完整干涉、承載與實物加工仍有界限；各能力、歷史變更及驗收證據見下方文件。
