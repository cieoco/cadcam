# SDD — 在原有流程中做減法

日期：2026-11-05（Asia/Taipei）

## 方向

保留能運作的機構設計、模擬、保存與輸出，刪除操作與程式的重複。每輪只處理一段已知麻煩的流程，實際操作後再決定下一輪。

本版取代先前的擴充提案：不新增理想驅動模型、目標資料層、A/B 比較系統或第二套工作區。那些規劃撤回，不作為後續實作任務。

## 交接現況：直接操作與參數設定（2026.11.6.3）

持續規則列在根目錄 AGENTS.md，Claude 由同一入口讀取。這次按既有操作族複查並補實作；沒有新增操作模式、第二套模型、公開 API 或作品欄位。

| 狀態 | 實際能力與界限 |
| --- | --- |
| 合成前核對姿態 | 尚未完整約束的機構可能保留舊畫面，合成候選須使用設定孔距重建所選桿段，再驗證外部連接。依使用者要求，相接桿段的軸線偏差在 1° 內時，於預覽對齊直線並提示；確認才提交，取消保留原作品。大於 1° 保留原夾角，不能為了合成改孔距或放行衝突固定點。沿用原候選與 solver，不以範例名稱分支。 |
| 尺寸拖曳取整 | 共用尺寸把手、夾爪爪尖及齒輪輸出半徑共用整數毫米吸附，取有效範圍內的整數；沒有可用整數則不改。拖曳只預覽，完成才提交；點選／取消不改原小數，復原可回原小數。參數保留原精度，滑軌六種尺寸與齒條長／槽長補 0.1 mm 輸入及保存；齒輪主面板孔距解除整數限定。位置拖動、姿態、視角、齒數等不套用此尺寸規則。 |
| 已完成共用孔辨識 | 原內部代號下拉選單改為零件名稱與編號按鈕；圖上同號可點選，選取／焦點標出同一零件輪廓和孔距線。沒有歧義時直接顯示尺寸。適用任意名稱的連桿、三點板、圓盤，不依 H06/H07 分支。 |
| 已完成雙輸入接線 | 原零件面板、共用孔數字、圖上孔距把手皆走 `memberEditor.setDimensionValue`。輸入中的小數不被重繪覆寫，Escape 可還原；不可達候選不提交，不暗改其他零件孔距。 |
| 已補滑軌缺口 | 底座長度、滑塊長度與軌道偏移補直接把手；六種滑軌尺寸共用 `dimensions()` 的值、範圍及 setter。數字／把手／加減使用同一修改、裝配核對與復原。細節收合時不畫其把手；刪除重複長度滑桿。B 端固定時保留該端並同步軌道偏移，重建後不移位；底座上限依保存格式為 1000 mm。 |
| 已完成手機共用規則 | 圖上尺寸選項視為零件操作，不誤收抽屜；點尺寸把手可開原數字欄。滑軌命中使用實際元件擁有者，與接點重疊時可明確選擇。橫向手機各零件共用右側編輯區，替換原針筒專用布局。 |
| 已補單支點方向 | 單端相接的未合成連桿與單支點三點板，端點拖曳及方向角數字共用接點移動驗證；方向以世界水平為 0°，不更改桿長。拖曳整度，數值保留小數，受多點連接限制時不提供假自由度。 |
| 已補剩餘連續參數 | 齒輪輸出孔在主畫布拖曳，原孔距與起始角度數字共用同一候選；鏈輪中心距增加共用尺寸把手。已安裝針筒伸出量可拖推桿旁把手或輸入頂列數字，不另開視窗。取消／點選保留精度，提交一次復原。 |
| 已刪重複與名稱特例 | 刪齒輪自訂孔位視窗的手動分支、針筒規格視窗的重複伸出量／活動臂長／範例按鈕。三孔共線直桿修改中間孔時保留兩端總長；夾爪同步依實際嚙合、共用孔與鏡射幾何辨識，唯一配對才連動。 |
| 已保留針筒雙輸入 | 已安裝固定環的位置、固定式方向，在主畫布拖曳或輸入數字；共用安裝候選、孔位核對、復原與保存。可轉式方向由機構決定。 |
| 明確能力界限 | 共用孔把手改的是選定零件的孔距，並非任意平面移孔。轉盤與短桿共用孔的世界位置仍受短桿長度及當前針筒伸出量約束；不能藉拖曳默默改它們。現有圓盤沒有獨立板面角度／任意多孔座標模型，本輪不擴充它。3D 仍為預覽與選取入口。 |

### 本輪程式複查與延用方式

下表對應後面的完整操作清單；「沿用」表示確認已有共同操作路徑，並非聲稱本輪重新人工實測所有排列組合。

| 操作群 | 圖上／數值的共同來源 | 本輪處理 |
| --- | --- | --- |
| 桿板孔距、合成段長、圓盤外徑、板寬、機架外框 | `member-dimensions`、`member-editor`、`editing-handles`；合成沿原 resize 規則 | 修共用孔所有權；其餘沿用，拒絕繞過盒體／齒輪配對鎖定 |
| 接點、自由件、機架與模組位置；板件外形點 | `input.moveNodeTo`／`setPointPosition`、`translateModule`、`plate-editor` 的局部座標及候選 | 沿用同一位移與裝配核對；不把姿態變化冒充改孔距 |
| 滑軌、滑塊、偏移與行程 | `slider-editor.dimensions()` → 既有幾何同步、共用裝配提交 | 刪掉五份重複修改程序，補三種直接操作，修固定 B 端重建及範圍一致性 |
| 齒輪輸出孔、齒條與鏈輪中心距 | `gear-hole-placement` 候選；原齒條 setter；鏈輪 `nudgeDrivenSprocket` | 主畫布直接改齒輪孔距／起始角度、鏈輪中心距，與原數字共用提交。占用齒輪孔或連到外部零件的從動鏈輪拒絕獨立移動；齒數／模數維持數值設定 |
| 馬達、針筒與試動 | 原安裝候選／提交、`syringe-editor`、`motion` | 連桿／齒輪馬達安裝方向可在主畫布拖曳或輸入角度；針筒共用弧形標記。試動、安裝方向與視角分開，不新增外殼 |
| 組立面、偏移、角碼、榫槽、盒體 | 原 face-mate 候選、tab-nut 參數、box 候選；重用 `dimensionHandle` | 沿用，裝配核對仍在確認之前；板厚與加工配合數字為主 |
| 新增、複製、鏡射、接合／拆開、固定／放開、刪除、存檔 | 既有建立與拓撲命令 | 不強造數字對應；建立後的尺寸／位置回原編輯入口 |
| 量尺、軌跡、播放及視圖 | 原唯讀量測、模擬／相機操作 | 不把量測讀值或轉視角當成零件編輯 |

後續新增連續幾何操作：先在原域定義可改的量、範圍與唯一 setter；數字欄與 `dimensionHandle` 都呼叫它，候選驗證與 `commitMountingEdit`／原專用提交不複製。圖上多個擁有者才要求選擇；每個限制以幾何能力判定，不依範例代號。未支援自由度必須說明，不能用新增空泛操作層掩飾。

驗收證據與發布結果見對應 [更新紀錄](TEACHING-CHANGELOG.md)。後續仍以實際操作摩擦點逐包修正，這不代表任意 3D CAD、任意移孔或實體加工驗證已完成。

## 第一包：針筒安裝

| 處理 | 內容 |
| --- | --- |
| 保留 | 既有固定／可轉安裝、真實承載與輸出孔、候選規劃、拖曳、數字微調、試動及加工檢查 |
| 合併 | 點圖安裝與精確修改使用同一個畫面、同一份候選、同一個確認 |
| 刪除 | 四步導覽、步驟解鎖狀態、快速／進階流程切換，以及「移動固定環／換固定位置／調整安裝」三個轉接入口 |
| 刪除 | 重複方向欄與四個方向捷徑；針筒尺寸只沿用既有尺寸設定視窗，不再抄一份欄位 |
| 不動 | 求解器、作品格式、既有範例幾何、馬達流程、舊鉸接作品相容契約 |

## 操作與驗收

- 新增：點固定機架位置、點輸出孔，連接有效即可試動並確認；同位置多個可接零件仍須選清楚。
- 修改：開針筒設定即能拖固定環／方向、微調及試動；從「連接與安裝方式」改機架、輸出端孔、固定方式與正背面。
- 手動指定方向後，接孔不覆寫方向。固定環在筒身上的位置不改底板孔。
- 尚未固定、缺輸出或無法求解時停用試動／確認並指出原因；單點可轉式不提供固定方向控制。
- 預覽不改作品，取消不留資料；確認一次復原，保存／分享重開仍可動。規格與加工沿用原入口及驗證。
- 390×844、360×640、橫向與桌機檢查；把手至少 44 CSS px，預覽與選項獨立、確認可見；檢查長字、捲動、3D 與錯誤訊息。
- 執行既有液壓瀏覽器驗收、相關 Node 驗收，補這次合併涉及的修改測試。證據記於教學更新紀錄。

### 裝配修改的共同規則（2026-11-05，2026.11.5.4）

問題：各種安裝已有自己的候選及幾何驗證，但針筒固定環等配對孔會從設定即時計算。原來只改安裝設定就會更新孔位，沒有統一的「是否改原孔」決策；拖曳與數值入口也各自提交。

本包直接接進既有提交流程，不新增操作模式、固定孔資料庫或外層工作區：

1. 上次已確認／已保存的作品為孔位基準。候選沿用原幾何生成器，`mounting-review.js` 比較兩份 `part-geometry` 的零件局部孔／槽，數值比較容差 0.01 mm 只排除浮點誤差，不是製造公差。
2. `mounting-review-ui.js` 共用確認及提交。拖曳和數字均先用候選；孔位改變才問「一起更新／返回調整」，不可在詢問前寫 undo 或存檔。接受是一筆修改，取消保留原作品；舊拖曳預覽的自存使用拖曳前快照。
3. 針筒只比較該固定環配對孔及推桿端參照；馬達只比較安裝／輪轂加工特徵；齒輪兩孔只比較實際配對孔，改爪尖不能誤問。板件角碼／榫槽使用同一接合描述與孔槽生成，不複製加工算法。
4. 同一關係的首次安裝由既有安裝確認負責；明確拆除維持原拆除契約。馬達以動力編號及所屬設計辨識，換輸出桿仍是原裝配的修改。試動、視圖變化、整件平移，以及筒身穿過不動的固定環不要求改孔。既有齒輪孔被占用時仍由原驗證拒絕，不因使用者答應改孔就拆開／破壞其他連接。
5. 分頁編輯需合併完整作品候選後核對，包含跨模組接合。共用接頭覆蓋針筒簡式／規格設定、馬達安裝／換型號、接點及整組移位、桿板及合成尺寸、齒輪／齒條、鏈輪、加工設定、組立接合與盒體確認。現有純幾何計算與保存格式不變；舊幾何 helper 讀取全域狀態者先以隔離候選轉接，不能在候選階段呼叫繪圖、保存或 undo。

驗收：H07 固定環拖曳／數值各測取消、接受、一次復原與保存重開；H08 試動不動固定孔；馬達方向／規格、角碼及榫槽移位、齒輪兩孔、跨模組候選均測差異；不可生成配對孔時拒絕提交。桌機及 390×844、360×640 手機驗收與截圖列在更新紀錄。

界限：這是「更新既有裝配時先確認孔位變更」，不把已加工板件當成可自動改孔；不保存獨立實物鑽孔版本，也不宣稱補齊所有接觸、承載、干涉或未支援零件的加工模型。缺少實體幾何的型號仍沿用待核對標記。以後新增同類操作必須接共用核對，不再各寫確認規則。

### 接點選取與尺寸操作的共同規則（2026-11-05）

問題：選零件可改孔距，選孔卻只進入姿態拖曳，使用者無法從眼前的孔找到尺寸操作。本包讓接點列出 `memberDimensions` 已有的孔距，不以圓盤形狀、範例編號或零件名稱分支。

- 一個可辨識的尺寸直接顯示；共用接點或三點板有多個尺寸時，明確選擇「要修改的零件孔距」。不擅自伸長所有相連零件。
- 孔距把手與數字欄共用 `memberEditor.setDimensionValue(componentId, dimensionId, value)`；原零件面板也改呼叫它。拖動預覽只改把手與數字，放開後沿原候選、裝配核對、一次復原與保存提交。
- 把手沿該尺寸方向改孔距，連接後實際位置仍由既有求解器決定；不是任意平面座標搬孔。一般接點拖曳仍是試調姿態。齒輪配對孔、盒體尺寸及合成尺寸繼續使用原限制與專用提交，不繞過鎖定。
- 孔距修改先驗證目前設計的候選姿態；不可解時保留原作品，不把錯誤留到提交後。這項檢查不等同全行程或實物驗證。

驗收：任意名稱的連桿、圓盤、三角板皆從同一份尺寸定義取得操作；H07/H06 共用孔不暗改短桿長；桌機滑鼠、手機觸控與精確輸入，驗證取消、不可達尺寸、一次復原及保存重開。

- 主畫布兩種輸入走 `planMotorAngle` 與 `commitMountingEdit`；只改安裝本體，保留軸心、輸出桿、驅動相位與播放角度。候選過期不提交，固定孔有差異時需確認；取消保留原作品及復原堆疊。
- `motor-orientation`／`motor-mounts` 的解析供視覺及孔位共用，2D／3D 的承載桿跟隨包含相對轉角；製作清單改用同一孔位方向解析，刪除重複推算。舊方向快捷命令共用一筆安裝提交，按需載入，首次載入仍維持既有大小上限。
- 適用目前有安裝語意的連桿與齒輪馬達（TT、MG995、N20）。鏈輪／凸輪的專用驅動尚無相同可保存安裝關係，本輪不冒充支援；N20 實體孔位、實際夾持與承載仍待核對。
