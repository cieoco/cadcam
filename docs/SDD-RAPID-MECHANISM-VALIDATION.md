# SDD — 在原有流程中做減法

日期：2026-11-05（Asia/Taipei）

## 方向

保留能運作的機構設計、模擬、保存與輸出，刪除操作與程式的重複。每輪只處理一段已知麻煩的流程，實際操作後再決定下一輪。

本版取代先前的擴充提案：不新增理想驅動模型、目標資料層、A/B 比較系統或第二套工作區。那些規劃撤回，不作為後續實作任務。

## 自由板材直接拖動（2026-11-09）

自由桿件、板材、L型件本體共用整件平移，手機格孔拖曳超過門檻後也可帶動自由板；輕點選孔保留。局部固定孔、共享孔、致動器與模組間接引用阻止自由平移。既有第一孔X／Y數值入口保留；拖動不改孔距、不吸附改尺寸，取消與一次復原沿既有流程。桌機板身平移70×50 px與復原、390×844手機板材30×40 px與L型件25×32 px已驗收；不宣稱受約束機構整組搬移或實機觸控已驗證。

## 孔圈視圖縮放（2026-11-09）

一般桿件／板材孔圈依毫米孔徑同比縮放，未用孔同樣縮放；透明選取區維持螢幕尺寸，縮小仍可點選。固定支點與馬達／凸輪符號屬操作標記，仍維持原尺寸；未變動作品尺寸或加工輸出。桌機／手機縮放與選孔已驗證，見更新紀錄。

## 針筒固定孔與單耳調向（2026-11-09）

- 已完成：雙孔固定預設以第一耳為安裝調向中心，第二耳保持24 mm孔距；拖曳角度與精確小數共用候選，原編輯面板確認／取消，一次復原。這是安裝方向調整，運作時仍兩孔鎖定。

- 部分支援：標準板勾選「保留已鑽的固定孔」後，舊固定孔寫入作品且保存重開仍保留，移除針筒也不抹掉；新孔不能與其衝突。自動機架的歷史已鑽孔保留尚未支援，會回報原因；輸出轉接板不接受此固定架安裝。縮放不可刪除已鑽孔。

- 驗收：`test/syringe-clamp-drilling.mjs`核對第一耳、24 mm、15.5°、停用／恢復、已鑽孔拆除保存、冪等、板邊及實際SVG／DXF；桌機與390×844手機核對拖曳／數字、取消、確認及復原，證據在`output/syringe-clamp-drilling/`。

## 零件直接設為機架（2026-11-09）

零件「其他操作」新增設為機架，一次固定既有p1/p2，沿用共用孔角色與裝配核對、一次undo和存檔；不新增type或機架模式。桿件沿既有frameSeparate保留自身板形，板材／L型沿固定板規則。既有兩個固定孔已鎖住的零件顯示「已設為機架」，不重複提交。只改角色，不吸附或改孔距；共用節點的角色同步更新。

馬達／致動器占用、固定後無解、目前孔位與孔距不符皆拒絕；非初始姿態要求回初始姿態，不暗改整個機構。合成件、盒體維持原流程，本入口不處理。解除固定沿既有孔位操作，剛完成可一次undo；沒有新增雙向切換，以免解除使用者原先固定的孔。

## 針筒安裝選取修正（2026-11-09）

安裝共用固定孔判定含局部格孔：同剛體兩個不同位置的固定孔鎖住整片板；同點重複孔、單孔或未固定板不能冒充機架。新增入口接受板材／L型件，圖選和清單共用候選；可轉安裝支援板材／L型件的主孔及局部孔，固定筒身仍需短連桿，不擴稱任意活動板皆可直接連接。參考環五金干涉仍待實物核對。

新增安裝在原畫布疊加可取消候選，桌機側欄／手機底欄保留原參數，不另開第二張設計圖；原作品只在確認後提交。板件面內定位、失敗提示、取消與一次undo已驗收；同孔多零件維持選擇。既有針筒修改仍沿原內嵌編輯器，未重做其流程。候選試動以虛線表示變動位置；不是正式作品姿態。

## 操作與驗收

- 新增：點固定機架位置、點輸出孔，連接有效即可試動並確認；同位置多個可接零件仍須選清楚。
- 修改：開針筒設定即能拖固定環／方向、微調及試動；從「連接與安裝方式」改機架、輸出端孔、固定方式與正背面。
- 手動指定方向後，接孔不覆寫方向。固定環在筒身上的位置不改底板孔。
- 尚未固定、缺輸出或無法求解時停用試動／確認並指出原因；單點可轉式不提供固定方向控制。
- 預覽不改作品，取消不留資料；確認一次復原，保存／分享重開仍可動。規格與加工沿用原入口及驗證。
- 390×844、360×640、橫向與桌機檢查；把手至少 44 CSS px，預覽與選項獨立、確認可見；檢查長字、捲動、3D 與錯誤訊息。
- 執行既有液壓瀏覽器驗收、相關 Node 驗收，補這次合併涉及的修改測試。證據記於教學更新紀錄。

### 後續修正的共同驗收

1. 同一個量只保留一份設定與驗證。拖動時預覽與數字同步，輸入有效數字時圖形同步；不增加模式開關。
2. 區分移動、改尺寸、試動與看視角。受約束無法移動時說明原因，不暗改其他孔距或拆開連接。
3. 一段拖曳對應一次確認／復原；取消、第二指與中斷不留半成品。數值輸入保留負號、小數編輯與原有精度。
4. 功能本身不是數值的，保留選擇；板厚、刀具、材料等以精確設定為主，不為追求對稱而硬加把手。
5. 每包刪掉被取代的分支與重複欄；各包分別驗收。尚未完成項目依上表如實保留，不把滑桿或視角拖曳充當完成。

### 裝配修改的共同規則（2026-11-05，2026.11.5.4）

問題：各種安裝已有自己的候選及幾何驗證，但針筒固定環等配對孔會從設定即時計算。原來只改安裝設定就會更新孔位，沒有統一的「是否改原孔」決策；拖曳與數值入口也各自提交。

本包直接接進既有提交流程，不新增操作模式、固定孔資料庫或外層工作區：

1. 上次已確認／已保存的作品為孔位基準。候選沿用原幾何生成器，`mounting-review.js` 比較兩份 `part-geometry` 的零件局部孔／槽，數值比較容差 0.01 mm 只排除浮點誤差，不是製造公差。
2. `mounting-review-ui.js` 共用確認及提交。拖曳和數字均先用候選；孔位改變才問「一起更新／返回調整」，不可在詢問前寫 undo 或存檔。接受是一筆修改，取消保留原作品；舊拖曳預覽的自存使用拖曳前快照。
3. 針筒只比較該固定環配對孔及推桿端參照；馬達只比較安裝／輪轂加工特徵；齒輪兩孔只比較實際配對孔，改爪尖不能誤問。板件角碼／榫槽使用同一接合描述與孔槽生成，不複製加工算法。
4. 同一關係的首次安裝由既有安裝確認負責；明確拆除維持原拆除契約。馬達以動力編號及所屬設計辨識，換輸出桿仍是原裝配的修改。試動、視圖變化、整件平移，以及筒身穿過不動的固定環不要求改孔。既有齒輪孔被占用時仍由原驗證拒絕，不因使用者答應改孔就拆開／破壞其他連接。
5. 分頁編輯需合併完整作品候選後核對，包含跨模組接合。共用接頭覆蓋針筒簡式／規格設定、馬達安裝／換型號、接點及整組移位、桿板及合成尺寸、齒輪／齒條、鏈輪、加工設定、組立接合與盒體確認。現有純幾何計算與保存格式不變；舊幾何 helper 讀取全域狀態者先以隔離候選轉接，不能在候選階段呼叫繪圖、保存或 undo。

驗收：H07 固定環拖曳／數值各測取消、接受、一次復原與保存重開；H08 試動不動固定孔；馬達方向／規格、角碼及榫槽移位、齒輪兩孔、跨模組候選均測差異；不可生成配對孔時拒絕提交。桌機及 390×844、360×640 手機驗收與截圖列在更新紀錄。

界限：這是「更新既有裝配時先確認孔位變更」，不把已加工板件當成可自動改孔；不保存獨立實物鑽孔版本，也不宣稱補齊所有接觸、承載、干涉或未支援零件的加工模型。缺少實體幾何的型號仍沿用待核對標記。以後新增同類操作必須接共用核對，不再各寫確認規則。

### 接點選取與尺寸操作的共同規則（2026-11-05）

問題：選零件可改孔距，選孔卻只進入姿態拖曳，使用者無法從眼前的孔找到尺寸操作。本包讓接點列出 `memberDimensions` 已有的孔距，不以圓盤形狀、範例編號或零件名稱分支。

- 一個可辨識的尺寸直接顯示；共用接點或三點板有多個尺寸時，明確選擇「要修改的零件孔距」。不擅自伸長所有相連零件。
- 孔距把手與數字欄共用 `memberEditor.setDimensionValue(componentId, dimensionId, value)`；原零件面板也改呼叫它。拖動預覽只改把手與數字，放開後沿原候選、裝配核對、一次復原與保存提交。
- 把手沿該尺寸方向改孔距，連接後實際位置仍由既有求解器決定；不是任意平面座標搬孔。一般接點拖曳仍是試調姿態。齒輪配對孔、盒體尺寸及合成尺寸繼續使用原限制與專用提交，不繞過鎖定。
- 孔距修改先驗證目前設計的候選姿態；不可解時保留原作品，不把錯誤留到提交後。這項檢查不等同全行程或實物驗證。

驗收：任意名稱的連桿、圓盤、三角板皆從同一份尺寸定義取得操作；H07/H06 共用孔不暗改短桿長；桌機滑鼠、手機觸控與精確輸入，驗證取消、不可達尺寸、一次復原及保存重開。

### 3D 預覽做減法（2026-11-05，2026.11.5.6）

摩擦點：手機看 H01 的 3D 時，常駐視角／分離、液壓計算、黃色製作提醒及機架摘要同時占用畫布。這一包只調整呈現，沒有新增操作模式、狀態模型或求解規則。

- 視角、分離及外觀尺寸沿用原工具，預設收在原生「視角」展開列；選好視角即收起，分離值不因此重設。
- 設計畫面頂端保留伸出量；原液壓讀值與製作提醒移到原狀態入口，桌機／手機共用原生 popover，刪除舊手機自訂詳情與黃色覆蓋層。求解錯誤仍有狀態提示，伸出量失敗另沿用即時通知。
- 唯讀 3D 隱藏設計編輯面板及手機摘要抽屜；點 3D 返回，或手機點新增／調整／專案回 2D。組立保持原針筒資訊；不改安裝、加工、存檔或復原契約。
- 驗收：1280×900、390×844、360×640、844×390；視角展收、分離、詳情、伸出量與復原、切回 2D、組立往返及無橫向溢出。瀏覽器腳本與證據見更新紀錄；未宣稱實體手機、完整干涉或實物加工驗證。

### 看見零件到開始修改（2026-11-05，2026.11.5.7）

使用者目標是快速驗證機構，不是繼續堆疊設定。此輪選擇「3D 看見零件 → 修改尺寸／安裝 → 復原」這一條路，沿原操作做減法：

- 原流程必須退出 3D、回圖面重新找零件；預覽單點還會讓零件變透明。現在設計預覽點到有明確擁有者的零件，返回 2D 並共用原選取／尺寸入口；馬達按實際軸心進入原安裝，針筒／管夾按針筒擁有者進入原安裝。手機直接顯示該欄，無新增屬性面板或操作模式。
- 命中沿用場景實際射線與材料 partId，滑軌／滑塊補上來源 id；不從畫面距離、孔名拆字、範例編號或鄰近零件猜擁有者。齒條沿用 2D 的所屬齒輪編輯，其他分頁與沒有既有編輯入口的參考五金不跳轉。隱性機架仍在 2D 修改。
- 預覽不修改幾何。拖離後回原點、雙指或取消不構成點選；組立保留原選面。獨立安裝預覽的既有透明檢視不改成選取編輯。
- 桿件、板件及合成尺寸已有圖上把手，刪除原面板的重複範圍滑桿及其載入分支，保留精確輸入、加減、範圍／鎖定、候選及一次復原。其他有明確用途的試動滑桿不刪。

### 既有針筒直接調整（2026-11-05，2026.11.5.8）

摩擦點：已安裝針筒每次改位置都再開安裝視窗，重複整個機構預覽、移動按鈕、試動滑桿與確認步驟。本包將這條日常路徑替換為既有主畫布＋屬性面板，不新增操作模式。

### 端孔旋轉與尺寸把手分離（2026-11-05，2026.11.5.12）

- 摩擦點：選端孔後，尺寸把手蓋住同一點，拖曳被解讀成改孔距；自由延長桿還可能經全機構約束迭代拉動原機構。
- 沿用既有操作，不增模式：點孔與選零件的尺寸把手都離端孔 48 CSS px，以細線指回端孔；尺寸仍共用原數值候選與驗證。端孔保留接點操作。
- 通則：固定長度、未合成、非驅動、未直接承載針筒的連桿，其自由端只屬於該桿、另一端已連接或固定時，先繞另一端旋轉，不進整組機構的牽動解算。共享孔、閉鏈與其他受約束點仍走原規則，不靠範例名稱判斷。
- 拖曳旋轉採整度，參數座標操作不取整；維持孔距，不量化衍生的 X/Y。點選不改值；Escape、觸控取消或第二指還原原精度；完成沿用一筆復原與孔位核對。
