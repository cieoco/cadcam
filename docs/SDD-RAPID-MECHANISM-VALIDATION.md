### 問題與目標

工具已由線段機構設計走向積木組裝，但部分資料與提交入口仍把零件存在、連接合法及運動可解綁在一起。結果是換孔、改桿長、改固定方式或改建立順序時，使用者無法先留下中間成果。補個別按鈕不能解決此問題。

目標是讓使用者完成「放置 → 嘗試連接 → 解除 → 修改 → 再接回 → 驗證運動 → 核對製作」，不強制依此順序操作。零件可先存在，合法的部分組裝可以保存；動作和加工是否成立由各自檢查回答。

「不限定順序」不代表所有接法都合法，也不代表求解器必須支援任意機構。不得以畫面重合冒充接合，不自動刪約束、改尺寸或補假桿件讓求解通過。

### 三個檢查時機

| 時機 | 必須檢查 | 不應因此阻擋 | 回饋與處理 |
| --- | --- | --- | --- |
| 編輯確認、保存重開 | 有限且有效的尺寸／座標、零件身分、接點引用、支援的接合類型、局部幾何相容、不得覆蓋已用孔 | 尚未連完、缺少固定點、整體欠約束、目前姿態或行程求解失敗 | 合法中間成果可保存；候選錯誤保留選擇並指明零件與修正方式 |
| 試動、播放 | 作用範圍、驅動與約束、目前姿態及適用的全行程檢查 | 不回頭禁止編輯、拆接或保存 | 不可播放則說明原因；失敗求解座標不得寫回正式作品 |
| 製作、輸出 | 所選零件的孔槽、邊距、外形、材料及適用格式／外購件分類 | 無關零件未裝好或整體還不能動 | 可核對板件仍可輸出；有加工衝突的零件明確阻擋，不宣稱實物就緒 |

檢查可以提前預告，不必等到按播放才知道問題；差別是預告不能冒充編輯的硬性門檻。未知的尺寸／支架／承載標示待核對；已知孔槽破邊、重複驅動或不支援的連接不能當作有效連接提交。不得移除現有加工保護來達成「都能確認」。

### 零件與連接的規則

1. 零件的尺寸、局部孔位與設計位置須可獨立保存。馬達沒有輸出件時也能存在；不能以隱藏桿件或零長桿取代獨立動力。
2. 連接須能辨識兩端零件及接孔／接面，並區分可旋轉、剛性固定及動力傳遞。介面先標明操作對象；共用孔有歧義時才要求具名選擇。
3. 「解除連接」只解除選定關係，保留零件、尺寸與其他連接。採用當下有限的顯示姿態轉成獨立設計位置；沒有可信姿態時保留原位置並說明，不能瞬移到原點或留下無效數字。
4. 解除與刪除分開。解除不刪零件；刪除仍須核對依賴。已實際鑽孔的紀錄不因拆下而消失；虛擬占用孔依剩餘連接重新計算，已被別件使用的孔不可擅自停用或改名。
5. 重新接回走原建立連接的同一候選與驗證。固定改可轉、換孔、換宿主也走同一修改入口，不要求先刪零件重建。
6. 本次不新增「暫時停用但仍保留約束」狀態；先用明確的未連接／已連接。未連接不能以不存在的零件 ID 表示；缺失引用與使用者主動拆開必須分得出來。
7. 拖曳與數字修改同一份候選；確認一次寫入與一次復原，取消不留零件或孔槽。確認前若作品／分頁已變更，拒絕過期提交。拖曳尺寸取整、精確輸入保留小數的既有規則繼續適用。

### 一般積木放下即新增（2026-11-10，本地）

使用者確認簡化一般桿件、板材、L型件的建立：點畫布放置、拖本體放開、拖尺寸把手完成，均直接走既有建立交易，不再要求「確認新增」。只點尺寸把手仍開精確欄位，不建立；數字輸入保留候選，按「放到畫布」後點位置即可。也可直接點候選本體，保留精確位置與小數尺寸。手機的「放到畫布」同時收合面板，移除重複「看畫布」按鈕。

實作沿 `standard-blank-ui.js` → `tools.js` 原路徑，未新增工作模式或儲存格式。空白／無效尺寸欄位會阻止放置舊候選，位置非有限數字由 `makeStandardBlank` 拒絕。

### 馬達放上標準承載件自動開孔（2026-11-10，本地）

新增 TT／N20／MG995 時點放、拖放或依座標放置，以及既有獨立馬達拖動本體／軸心放上標準桿件或矩形板材，均由 `planMotorDrop` 選最近可用孔，再沿用 `planMotorInstallation` 建立真實外殼固定與孔槽。畫布、占用孔及 DXF 共用既有幾何，不以重合冒充安裝；新增與拖移各維持一次復原。自由板材可承載未接輸出的馬達，不自動設為機架；解除外殼固定恢復虛擬占用格孔。

跨模組、輸出板及重疊承載件不自動猜接；標準桿件亦檢查安裝孔槽足跡、板邊、已用格孔與既有加工孔。新件無效候選留在原側欄修正；既有獨立馬達拖放失敗保留落點與獨立身分，提示未安裝。延遲載入完成時若作品已改變則放棄舊結果，不能覆蓋後續操作。空白處仍自由放置。此規則取代下方歷史紀錄中標準承載件上的「僅位置對齊」；一般精確座標編輯與任意已裝配整組拖移未擴充。

尺寸界限：MG995 現行預設線槽仍有螺絲干涉，保留拒絕；測試使用明確的 6×2 mm 試作線槽，不改全域預設。N20 通用模擬規格沒有指定加工孔，須選既有前端孔試作規格；窄桿放不下 TT／MG995 不暗改桿寬。L型件、移動板材接輸出的任意拓樸及實物製作驗證不屬本包。

驗收：`motor-drop` 覆蓋三型號、兩種順序、孔槽／DXF、取消／過期、一次復原、刪除恢復與保存重開；`independent-motors`、`actuator-installation`、`actuator-standard-plates`、`input-gestures`（59/59）、`startup-size`（12/12）通過。馬達瀏覽器專項桌機及390×844觸控事件各243/243，包含解除承載與失敗後繼續編輯。實際原畫布拖TT至板格孔，側欄確認承載為矩形板材；證據 `output/auto-motor-mount/`。載入圖核對通過，維持2.162 MB既有啟動預算。僅本地試用，未commit／push，未宣稱實機觸控或實物加工完成。

MG995 舵盤外露修正：3D原先將3 mm示意舵盤放在承載板背面，造成埋入板厚。現在按承載板實際厚度與正反面，將完整舵盤置於輸出側板面外0.5 mm，軸延伸穿過舵盤；已有輸出件時，預覽疊層保留舵盤厚度及兩側間隙。這是3D裝配示意定位，未更改2D孔位／加工槽、實物軸長或未量測線槽規格。3／6／10 mm板厚與正反面、輸出件間隙、既有3D範例及安裝測試通過；首次JS實測2,162,218 bytes，上限依增量調為2.163 MB，viewer仍按需載入。本地3D畫面另行檢視，未發布。

### 先放動力再放輸出桿（2026-11-10，本地）

新增標準桿件的端孔吸附到既有獨立動力軸心，或自由畫桿的起／終孔接到該軸心時，視為接上輸出的意圖，沿用 `planMotorInstallation`；不再只有共用接點卻仍顯示「未接輸出」。沿用同一個動力身分、外殼承載、方向與舵機範圍，放置與接輸出共一筆復原；不另開設定視窗。精確座標必須實際對到同一孔，鄰近但未吸附不猜接。後續補上已有自由桿件的端孔拖接（見下）；任意板材與已連輸出的改接不在本包。

### 桌機 Enter／Delete（2026-11-10，本地）

標準桿件／板材／L型預覽可按 Enter 放置；馬達／舵機安裝按 Enter 呼叫目前既有確認或依座標放置入口，數值欄先完成編輯再驗證。開啟面板移入焦點，避免 Enter 重複觸發新增工具。原生按鈕、選單、文字區、中文組字與修飾鍵保留原作用，不全域猜測任何「確認」按鈕。

### 本輪程式複查與延用方式

下表對應後面的完整操作清單；「沿用」表示確認已有共同操作路徑，並非聲稱本輪重新人工實測所有排列組合。

| 操作群 | 圖上／數值的共同來源 | 本輪處理 |
| --- | --- | --- |
| 桿板孔距、合成段長、圓盤外徑、板寬、機架外框 | `member-dimensions`、`member-editor`、`editing-handles`；合成沿原 resize 規則 | 修共用孔所有權；其餘沿用，拒絕繞過盒體／齒輪配對鎖定 |
| 接點、自由件、機架與模組位置；板件外形點 | `input.moveNodeTo`／`setPointPosition`、`translateModule`、`plate-editor` 的局部座標及候選 | 沿用同一位移與裝配核對；不把姿態變化冒充改孔距 |
| 滑軌、滑塊、偏移與行程 | `slider-editor.dimensions()` → 既有幾何同步、共用裝配提交 | 刪掉五份重複修改程序，補三種直接操作，修固定 B 端重建及範圍一致性 |
| 齒輪輸出孔、齒條與鏈輪中心距 | `gear-hole-placement` 候選；原齒條 setter；鏈輪 `nudgeDrivenSprocket` | 主畫布直接改齒輪孔距／起始角度、鏈輪中心距，與原數字共用提交。占用齒輪孔或連到外部零件的從動鏈輪拒絕獨立移動；齒數／模數維持數值設定 |
| 馬達、針筒與試動 | 原安裝候選／提交、`syringe-editor`、`motion` | 連桿／齒輪馬達安裝方向可在主畫布拖曳或輸入角度；針筒共用弧形標記。試動、安裝方向與視角分開，不新增外殼 |
| 組立面、偏移、角碼、榫槽、盒體 | 原 face-mate 候選、tab-nut 參數、box 候選；重用 `dimensionHandle` | 沿用，裝配核對仍在確認之前；板厚與加工配合數字為主 |
| 新增、複製、鏡射、接合／拆開、固定／放開、刪除、存檔 | 既有建立與拓撲命令 | 不強造數字對應；建立後的尺寸／位置回原編輯入口 |
| 量尺、軌跡、播放及視圖 | 原唯讀量測、模擬／相機操作 | 不把量測讀值或轉視角當成零件編輯 |

後續新增連續幾何操作：先在原域定義可改的量、範圍與唯一 setter；數字欄與 `dimensionHandle` 都呼叫它，候選驗證與 `commitMountingEdit`／原專用提交不複製。圖上多個擁有者才要求選擇；每個限制以幾何能力判定，不依範例代號。未支援自由度必須說明，不能用新增空泛操作層掩飾。

驗收證據與發布結果見對應 [更新紀錄](TEACHING-CHANGELOG.md)。後續仍以實際操作摩擦點逐包修正，這不代表任意 3D CAD、任意移孔或實體加工驗證已完成。

## 操作與驗收

- 新增：點固定機架位置、點輸出孔，連接有效即可試動並確認；同位置多個可接零件仍須選清楚。
- 修改：開針筒設定即能拖固定環／方向、微調及試動；從「連接與安裝方式」改機架、輸出端孔、固定方式與正背面。
- 手動指定方向後，接孔不覆寫方向。固定環在筒身上的位置不改底板孔。
- 尚未固定、缺輸出或無法求解時停用試動／確認並指出原因；單點可轉式不提供固定方向控制。
- 預覽不改作品，取消不留資料；確認一次復原，保存／分享重開仍可動。規格與加工沿用原入口及驗證。
- 390×844、360×640、橫向與桌機檢查；把手至少 44 CSS px，預覽與選項獨立、確認可見；檢查長字、捲動、3D 與錯誤訊息。
- 執行既有液壓瀏覽器驗收、相關 Node 驗收，補這次合併涉及的修改測試。證據記於教學更新紀錄。

### 裝配修改的共同規則（2026-11-05，2026.11.5.4）

問題：各種安裝已有自己的候選及幾何驗證，但針筒固定環等配對孔會從設定即時計算。原來只改安裝設定就會更新孔位，沒有統一的「是否改原孔」決策；拖曳與數值入口也各自提交。

本包直接接進既有提交流程，不新增操作模式、固定孔資料庫或外層工作區：

1. 上次已確認／已保存的作品為孔位基準。候選沿用原幾何生成器，`mounting-review.js` 比較兩份 `part-geometry` 的零件局部孔／槽，數值比較容差 0.01 mm 只排除浮點誤差，不是製造公差。
2. `mounting-review-ui.js` 共用確認及提交。拖曳和數字均先用候選；孔位改變才問「一起更新／返回調整」，不可在詢問前寫 undo 或存檔。接受是一筆修改，取消保留原作品；舊拖曳預覽的自存使用拖曳前快照。
3. 針筒只比較該固定環配對孔及推桿端參照；馬達只比較安裝／輪轂加工特徵；齒輪兩孔只比較實際配對孔，改爪尖不能誤問。板件角碼／榫槽使用同一接合描述與孔槽生成，不複製加工算法。
4. 同一關係的首次安裝由既有安裝確認負責；明確拆除維持原拆除契約。馬達以動力編號及所屬設計辨識，換輸出桿仍是原裝配的修改。試動、視圖變化、整件平移，以及筒身穿過不動的固定環不要求改孔。既有齒輪孔被占用時仍由原驗證拒絕，不因使用者答應改孔就拆開／破壞其他連接。
5. 分頁編輯需合併完整作品候選後核對，包含跨模組接合。共用接頭覆蓋針筒簡式／規格設定、馬達安裝／換型號、接點及整組移位、桿板及合成尺寸、齒輪／齒條、鏈輪、加工設定、組立接合與盒體確認。現有純幾何計算與保存格式不變；舊幾何 helper 讀取全域狀態者先以隔離候選轉接，不能在候選階段呼叫繪圖、保存或 undo。

驗收：H07 固定環拖曳／數值各測取消、接受、一次復原與保存重開；H08 試動不動固定孔；馬達方向／規格、角碼及榫槽移位、齒輪兩孔、跨模組候選均測差異；不可生成配對孔時拒絕提交。桌機及 390×844、360×640 手機驗收與截圖列在更新紀錄。

界限：這是「更新既有裝配時先確認孔位變更」，不把已加工板件當成可自動改孔；不保存獨立實物鑽孔版本，也不宣稱補齊所有接觸、承載、干涉或未支援零件的加工模型。缺少實體幾何的型號仍沿用待核對標記。以後新增同類操作必須接共用核對，不再各寫確認規則。

### 接點選取與尺寸操作的共同規則（2026-11-05）

問題：選零件可改孔距，選孔卻只進入姿態拖曳，使用者無法從眼前的孔找到尺寸操作。本包讓接點列出 `memberDimensions` 已有的孔距，不以圓盤形狀、範例編號或零件名稱分支。

- 一個可辨識的尺寸直接顯示；共用接點或三點板有多個尺寸時，明確選擇「要修改的零件孔距」。不擅自伸長所有相連零件。
- 孔距把手與數字欄共用 `memberEditor.setDimensionValue(componentId, dimensionId, value)`；原零件面板也改呼叫它。拖動預覽只改把手與數字，放開後沿原候選、裝配核對、一次復原與保存提交。
- 把手沿該尺寸方向改孔距，連接後實際位置仍由既有求解器決定；不是任意平面座標搬孔。一般接點拖曳仍是試調姿態。齒輪配對孔、盒體尺寸及合成尺寸繼續使用原限制與專用提交，不繞過鎖定。
- 孔距修改先驗證目前設計的候選姿態；不可解時保留原作品，不把錯誤留到提交後。這項檢查不等同全行程或實物驗證。

驗收：任意名稱的連桿、圓盤、三角板皆從同一份尺寸定義取得操作；H07/H06 共用孔不暗改短桿長；桌機滑鼠、手機觸控與精確輸入，驗證取消、不可達尺寸、一次復原及保存重開。
