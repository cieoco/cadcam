# SDD — 六面體組立精靈

日期：2026-10-07。使用者已授權規畫並依 LOOP、多模型方式進行工作。

## 產品成果

手機以大卡片完成「選兩機構 → 選兩接合面 → 置中／靠邊／偏置 → 預覽確認」。電腦保留工程工作模式；裝置佈局與操作方式分開，可手動切換。六面體是選方向與排列的代理外框，不代表實際板件或可加工接合面。

外框以安裝參考姿態建立，不隨動畫重新計算尺寸。宿主先指定底座或輸出構件（例如工具架），子機構才能跟隨正確構件運動。面名稱相對機構基準；相機旋轉不改變名稱。

## LOOP 與分工

## W1 契約

新增 `js/blocks/face-mate.js`，純邏輯，無 DOM／Three.js／S 相依。

- box：`{ min:{x,y,z}, max:{x,y,z} }`，每軸正尺寸，有限 number。
- face：`right/left/front/back/top/bottom`；X 右、Y 前、Z 上。每面提供中心、外法向 n、面內 u/v、寬／高；u × v = n。
- `solveFaceMate({hostBox, childBox, hostFace, childFace, alignU=0, alignV=0, offsetU=0, offsetV=0, gap=0, quarterTurns=0})`。
- alignU/V 為 -1/0/1，表示面內負向边／中心／正向边對齊；偏置沿宿主面的 u/v，單位 mm，不跟相機變化。quarterTurns 為 0..3；gap ≥ 0。
- 成功 `{ok:true, rotation, translation, host, child}`；rotation 是 3×3 行矩陣，點以 R*p+t 變換。失敗 `{ok:false, reason}`。另 export `boxFaces` 與 `transformMatePoint`。
- 子面外法向轉向宿主外法向反方向；旋轉行列式 +1；子面中心在宿主面法向方向 gap mm。奇數 90° 朝向交換面內寬高。

## W2 介面與驗收

### 接合面箭頭與尺寸（使用者追加授權）

對齊步驟把控制放在模型接合處：四向箭頭與中央置中。箭頭沿宿主面內 u/v 投影方向顯示，隨觀看旋轉更新。預設「移動」以可設定步距調 offset；「靠邊」令所選軸 align 為 ±1 並清該軸 offset，另軸保留，連點兩方向可靠角。中央置中清兩軸 align 與 offset。

尺寸用短標籤「左右／上下／間距／步距」，點選才開單一數值輸入。左右上下是面內偏置，允許負值；間距 ≥0；步距 >0。確定前是輸入草稿，取消／Escape 不改擺放；確定即時重畫。原型的整筆確認／取消與90°轉向沿用。手機精靈收掉九宮格、三排输入與長摘要；桌面工作模式保留精確設定。

驗收：箭頭 +5 mm、改步距2.5→箭頭、靠邊／靠角、置中清偏置、負偏置精確輸入、取消／Escape與非法數值、視角旋轉後箭頭方向／所選面不變、手機44px命中範圍及操作不觸發相機拖曳。

新增 `assembly-wizard-prototype.html` 與 `js/blocks/face-mate-prototype.js`，HTTP 靜態載入，無套件安裝。示例為兩個明確標示的代理盒，代表升降工具架／夾爪，非真實作品。

手機單一步驟與底部控制，3D 示意由 SVG 等角投影、可見面按深度排列、選中面突出顯示。六面大按鈕皆 ≥44 px；九宮格：靠角／靠邊／置中。偏置 u/v 與間距提供 ±5 mm 及精確輸入，轉向提供 90°。顯示當前接法摘要。桌面工作模式可同時顯示設定；精靈／工作可切換。確認僅保存到原型記憶體，取消回已確認狀態；不讀寫 localStorage、不載入或覆蓋使用者作品。

獨立驗收：手機 390×844、桌面 1280×800；六面選取、置中→靠右→偏置、90°、返回、確認後修改再取消。幾何測試不是觸控硬體／實物加工驗收。

## W3 前須解決

W3a（2026-10-07）已完成：`mount-surfaces.js` 使用既有 exporters 建立模組自有固定底板、bar／triangle／rack 輸出板的輪廓／孔／槽／板厚描述。板厚座標 ±t/2 是接合板參考，不是完整機構包圍盒或世界疊層。frame warnings 明示尚未合併馬達安裝與轉接座特徵；rack 加工 fallback 與 3D 預設不同亦明示。原型範例明確傳 4 mm 參考板厚，顯示真實工具架／滑台與夾爪底板，移除虛構進料範例。

W3b 已加入第一段姿態驗證：`face-placement.js` 把原型中心化座標還原為兩接合板的模組座標，輸出版本化擺放記錄與相容性結果。288 種姿態驗證真實輪廓／孔座標、JSON 往返與輸入隔離。確認後可下載已確認記錄，未確認修改不混入記錄。高度差、翻面及完整 3D 姿態仍不能寫成舊 mount；平面可表達也須驗證宿主輸出參考及固定接口。W3b 尚未完成 mount 映射，未產生孔位或新增 mount 欄位，不得當作可製造組立。

現有 mount 以 2D 輸出位姿與特定直角邊安裝為主，無通用六面體 3D 剛體安裝契約。任意代理盒接合不能直接寫成現有 mount。先做可表達接法映射，無法精確映射時清楚標示為「擺放預覽」，禁止生成錯誤固定孔或悄悄選最近邊。若需新增持久化姿態，主模型補充 schema／solver／3D／製作包一致性契約與回歸案例後才施工。

## W3b／W4 正式整合完成（2026-10-07）

以上為逐輪施工記錄；本節取代前述「尚未整合」狀態。正式入口為組立台選取未安裝模組，再開「六面體精靈」。選中面變色，模型可旋轉；手機箭頭沿接合面投影向外，點選後開尺寸草稿，確認才套用。關閉不改作品，整筆確認只增加一次復原紀錄。

新增 mount.face v1：proper rotation 3×3、translation、selection、兩接合板厚度。子模組保留本地 XY／板中心 Z=0，宿主輸出 home 參考驅動動態姿態；3D 補回各板實際疊層中心。支援 bar／triangle／rack 輸出與固定底板，以及六面接法鏈；既有平面或直角安裝宿主不混用新契約。schema、JSON／分享、拆下與設計移動均保留契約。尺寸／加工板厚變更時重算接合基準，維持所選面、對齊及間距。

本功能完成設計擺放與運動預覽；沒有生成跨面轉接件、配對固定孔或跨面干涉認證。組立狀態及製作包明示這個限制。參考底板也未合併馬達／轉接座特徵，不能視作實物完整包圍盒。

驗收包含純幾何、288 組 3D 板中心／姿態、尺寸更新、原生孔保留、拆下、移動、JSON／分享，以及 HTTP 手機與桌面正式介面確認／取消／復原。主入口載入無 console error。完整 Node 驗收使用 --no-experimental-webstorage；assembly-schema、solve-health、trace-fallback 的既有失敗以改動前 HEAD 重跑確認相同，未順便修改。
