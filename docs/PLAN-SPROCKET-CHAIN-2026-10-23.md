## 0. 目標

學生能在機構積木裡放兩個鏈輪、套上一條 #25 鏈條：
- 看得懂鏈條傳動：同向、齒數比、鏈節必須是整數。
- 能調齒數與中心距。
- 能驅動下游連桿。
- 最後輸出可製作的檔案與零件清單。

## 1. #25 鏈條規格（設計基準）

數值取自 Tsubaki RS25（ASA 25）商品頁，實物買到後要再量一次。

| 項目 | 數值 |
| --- | --- |
| 節距 p | 6.35 mm（1/4 in） |
| 滾子直徑 | 3.30 mm |
| 內寬（內鏈板之間） | 3.18 mm |
| 銷徑 | 2.31 mm |
| 鏈板高 | 5.84 mm |
| 鏈板厚 | 0.75 mm |
| 總寬 | 7.6 mm |
| 最小破斷負載 | 4,100 N |

由此推出的設計限制：
- **鏈輪齒厚要比 3.18 mm 小**，業界常用約 2.8 mm。3 mm 夾板切出來可能卡在鏈條內寬，要實測。
- **節圓直徑**：D = p ／ sin(180°／N)。
- **外徑（ANSI 近似）**：Do ≈ p × (0.6 ＋ cot(180°／N))。
- **鏈長（節數）**：L = 2C／p ＋ (N₁＋N₂)／2 ＋ p·(N₂−N₁)²／(4π²·C)。L 要取整數，最好是偶數；奇數要用半節（offset link）。
- **反推中心距**：由整數 L 反算 C，就是「剛好不鬆不緊」的建議中心距。
- **小鏈輪包角**：建議 ≥ 120°。

## 2. 現有基礎（盤點）

系統已有皮帶輪（`pulley`）＋開口皮帶（`belt`），而且已經接通這些地方：
- 求解器：`js/multilink/solver.js`，開口皮帶同向、角速度比為半徑反比。
- 資料：`schema.js`、`part-types.js`。
- 畫面：2D `transmission-render.js`／`transmission-geometry.js`（外公切線與包覆弧），3D `scene-model.js`。
- 範例與測試：`pulley-belt`。

但皮帶輪不在「新增 → 傳動」選單裡，只能從範例開。

**建議做法**：鏈輪當成「有齒的皮帶輪」，鏈條當成「有節距的開口皮帶」。資料上延用 `pulley`／`belt`，加上 `kind:'sprocket'`、`teeth`，以及 `kind:'chain'`、`standard:'25'`、`links`。節圓半徑由齒數算出，不讓學生直接改。

這樣求解、3D、存檔、組立都沿用現有程式，只補鏈條特有的部分：齒形、整數鏈節、滾子動畫、製作輸出。

## 3. 學生要學的

- **K1 同向傳動**：鏈條兩輪同向，和齒輪對反向不同。
- **K2 速比由齒數決定**：ω₂／ω₁ ＝ N₁／N₂，和皮帶的半徑比是同一件事，但不會打滑。
- **K3 鏈節是整數**：中心距不能隨便定。要嘛照建議中心距放，要嘛用長孔或張緊輪吃掉差值。
- **K4 小鏈輪齒數太少**：轉動會一頓一頓（多邊形效應）；包角太小容易跳齒。
- **K5 材料與厚度**：齒厚要能放進鏈條內寬。

## 4. 分期

### S1 核心（Sonnet；測試由 Opus 寫）

- **資料**：`pulley` 加 `kind:'sprocket'`、`teeth`（範圍待定，見 §5），`belt` 加 `kind:'chain'`、`standard:'25'`。讀檔時驗證並修正。
- **純函式** `js/core/chain-drive.js`：`pitchDiameter`、`outsideDiameter`、`chainLinks(C,N1,N2)`、`centerForLinks(L,N1,N2)`、`wrapAngle`、`checkChainDrive`。`checkChainDrive` 回報鏈節非整數的偏差 mm、奇數節、包角不足、齒數超出範圍、兩輪干涉。
- **求解**：鏈條半徑取節圓，速比等於齒數比，同向；鏈輪 p2 輪緣銷可接下游連桿。
- **範例** `sprocket-chain`：TT 驅動 12 齒 → 24 齒，中心距為整數鏈節，從動輪帶一支曲柄。
- **驗收**：
  - 速比誤差 < 0.1%，而且同向；
  - 建議中心距反算回去的鏈節是整數（誤差 < 0.01 mm）；
  - 偏離時能報出偏差；
  - 舊的皮帶輪範例不變。

### S2 介面（Sonnet）

- 「新增 → 傳動」加「鏈輪＋鏈條（#25）」：點主動輪中心、再點從動輪中心，自動放在最接近的整數鏈節位置。
- 鏈輪面板只露**齒數 ±**。鏈條面板顯示「鏈節 N 節（偶數）、中心距 C mm」，並有一顆「對齊整數鏈節」。
- 其餘收進「更多」：建議中心距、偏差、包角。
- 畫面：鏈輪畫齒；鏈條畫成沿路徑排列的滾子，播放時滾子沿鏈條前進。偏差或包角有問題時，鏈條變色並提示原因。
- 驅動沿用齒輪的「使用 TT／MG995」與中心驅動孔。
- **驗收**：手機 390×844 截圖，從空白做到兩輪轉動的點按次數，播放時沒有錯誤訊息。

### S3 製作與 3D（Sonnet）

- **鏈輪外形**：照 ANSI 齒形近似，輸出 SVG／DXF，帶中心孔與 TT／MG995 驅動孔，沿用 `gear-drive-hole`。厚度依 §5 的決定，CNC 警告提醒厚度是否小於 3.18 mm。
- **製作包**：鏈條列入購買清單（規格、節數、接頭或半節）。張緊方式依 §5 的決定，例如從動輪軸孔改為長孔（±½ 節）。
- **3D**：鏈輪齒盤；鏈條用滾子與鏈板的簡化外形沿路徑排列。
- **驗收**：
  - 輸出的齒數、節圓、外徑與公式一致；
  - 製作包列出鏈條節數；
  - 3D 截圖。

### S4 教材（Haiku 寫文字、Opus 審）

- 新單元「鏈條傳動」：先和齒輪對比轉向，再改齒數看速比；改中心距，看鏈節不是整數時會怎樣，再用「對齊整數鏈節」或長孔解決。
- 過關：交 MP4，並說出速比與鏈節數。

## 5. 需要使用者決定的事

1. **鏈輪怎麼做**：買現成金屬 #25 鏈輪（系統只出轉接座）、3D 列印，還是 CNC 切？CNC 切的話，材料厚度要 ≤ 2.8 mm 左右。
2. **齒數範圍**：例如 9～40 齒。
3. **中心距的處理**：自動對齊整數鏈節；或保留長孔讓學生張緊；或加張緊輪（較複雜，建議以後再做）。
4. **範圍**：第一版只做兩輪一條鏈，還是要多軸或惰輪？
