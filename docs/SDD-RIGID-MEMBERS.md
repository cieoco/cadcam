# 統一桿件：孔位決定運動，外形決定實體

最高原則沿用 SDD-FTC-MODULES：教學與應用兼具的快速原型＋數位樂高。

## 共用設計

直桿、折線桿、結構板、夾爪板都是剛性零件；共用選取、孔位連接、尺寸、疊放、復原及保存。折彎不是鉸鏈。兩個零件共孔才形成連接關係。

尺寸分成連接孔距與外形尺寸，不再用「底邊／邊 1／邊 2」讓使用者猜。選取後在畫布標 A/B/C，標明正在改的距離；同一列提供精確值與 ±8 mm。輸入不合法時拒絕整筆修改，不能先破壞幾何再顯示錯誤。

夾爪保留原始三個求解孔；新增可明確調整的爪端長度，屬外形、不改孔位。幾何、預估開口、2D、3D 及加工輪廓必須讀取同一個值。舊檔無此欄位時保留原有比例式爪端。

## 本輪可操作成果 R1c

1. 直桿與三點桿共用孔距名稱與精確輸入；畫布上的尺寸與選單一致，尺寸線可以選取。
2. 夾爪可從同一尺寸列調整爪端長度；預設對稱任務可以同步左右，單次一筆復原。只在原有對称對成立時同步，不猜測其他零件的配對。
3. 驅動孔距被齒輪決定時不能從夾爪單獨改壞；說明需改齒輪輸出孔設定。一般折線桿改段長維持彎角，修改跨距才改彎角；夾爪的 A–B / A–C 才是實體兩段。
4. 夾爪尚不支援的自由外形控制不得呈現成能用卻沒效果的按鈕。普通板件保留原有外形點功能，不強制遷移舊作品。
5. 修正有限行程播放在窄範圍／端點可能卡住的反射演算法。

## 驗收

- M1：bar/triangle/jaw 的尺寸描述、畫布標示、精確值一致；18 + 8 = 26，不暗中取整成 24。
- M2：無效數值或三角不等式不成立時不改 params、不改座標、不產生復原；有效修改先暫停、僅一筆復原。
- M3：爪端調整不動三個孔；左右同步可取消；有效對稱幾何重新規劃，非對稱不能冒充有效任務。
- M4：爪端值經 schema/分享/保存保留；舊檔輪廓不變；2D/3D/匯出/開口共用幾何。
- M5：有限往返在兩端皆可起播，多次越界仍在範圍內。
- M6：實際瀏覽器操作孔距選取、爪端修改、復原、播放；不新增常駐面板或遮住畫布。

## 後續而非本輪完成

直接拖動爪端、全類型板寬與材料／孔徑一致性、夾爪自由外形與鏡像約束、碰撞與實物驗證需各自驗收。此輪不宣稱完成製造能力，也不把爪端長度等同夾持力。
