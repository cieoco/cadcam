# 統一桿件：孔位決定運動，外形決定實體

最高原則沿用 SDD-FTC-MODULES：教學與應用兼具的快速原型＋數位樂高。

## 共用設計

直桿、折線桿、結構板、夾爪板都是剛性零件；共用選取、孔位連接、尺寸、疊放、復原及保存。折彎不是鉸鏈。兩個零件共孔才形成連接關係。

尺寸分成連接孔距與外形尺寸，不再用「底邊／邊 1／邊 2」讓使用者猜。選取後在畫布標 A/B/C，標明正在改的距離；同一列提供精確值與 ±8 mm。輸入不合法時拒絕整筆修改，不能先破壞幾何再顯示錯誤。

夾爪保留原始三個求解孔；新增可明確調整的爪端長度，屬外形、不改孔位。幾何、預估開口、2D、3D 及加工輪廓必須讀取同一個值。舊檔無此欄位時保留原有比例式爪端。

## 本輪可操作成果 R1c

1. 直桿與三點桿共用孔距名稱與精確輸入；畫布上的尺寸與選單一致，尺寸線可以選取。
2. 夾爪可從同一尺寸列調整爪端長度；預設對稱任務可以同步左右，單次一筆復原。只在原有對称對成立時同步，不猜測其他零件的配對。
3. 驅動孔距被齒輪決定時不能從夾爪單獨改壞；說明需改齒輪輸出孔設定。一般折線桿改段長維持彎角，修改跨距才改彎角；夾爪的 A–B / A–C 才是實體兩段。
4. 夾爪尚不支援的自由外形控制不得呈現成能用卻沒效果的按鈕。普通板件保留原有外形點功能，不強制遷移舊作品。
5. 修正有限行程播放在窄範圍／端點可能卡住的反射演算法。

## 驗收

- M1：bar/triangle/jaw 的尺寸描述、畫布標示、精確值一致；18 + 8 = 26，不暗中取整成 24。
- M2：無效數值或三角不等式不成立時不改 params、不改座標、不產生復原；有效修改先暫停、僅一筆復原。
- M3：爪端調整不動三個孔；左右同步可取消；有效對稱幾何重新規劃，非對稱不能冒充有效任務。
- M4：爪端值經 schema/分享/保存保留；舊檔輪廓不變；2D/3D/匯出/開口共用幾何。
- M5：有限往返在兩端皆可起播，多次越界仍在範圍內。
- M6：實際瀏覽器操作孔距選取、爪端修改、復原、播放；不新增常駐面板或遮住畫布。

## R1c 時列為後續的項目

R1c 未完成直接拖動爪端、板寬與材料／孔徑一致性；R1d 見下方。夾爪自由外形與通用鏡像約束、碰撞與實物驗證仍需另行驗收，不把爪端長度等同夾持力。

## R1d：直接拖爪端與實體資料（已完成的前一輪）

- 拖曳 T 把手沿既有爪端方向調長短（8–160 mm），不改彎角或三個孔。沿用同步左右選項；Escape、pointercancel、失去捕捉會取消；預覽不進 snapshot，放開才一筆復原。方向鍵可微調 1 mm。
- bar 與 triangle（包括夾爪）共用可選 `stock: { widthMm, thicknessMm, material }`。無此欄位採畫布原值 18 mm 寬、3D 原值 4 mm 厚、材料未指定，不重寫舊檔。
- 板寬指直桿／折線的實體寬度；包絡板與多邊形板採半板寬向外擴框，不是整片外接矩形寬。孔位置、孔徑與 solver 不隨板寬修改。厚度用於 3D 幾何與製作資料；材料為未指定／夾板／壓克力／鋁板／PLA，僅標籤，沒有強度、切削或列印參數認證。
- 既有編輯列加入「板寬／厚度」，材料採同一編輯區內的一個選單，不另增面板。對稱夾爪可沿用左右同步。寬度不得小於當前連接孔直徑加 0.5 mm（只是幾何留料，不是強度保證）。
- `stock` 是 2D、3D、SVG／DXF、製作記錄、保存／分享的共同來源。原全域匯出桿寬改稱「機架樑寬」，僅用於自動機架；一般桿板不再被另一份匯出寬度蓋掉。帶馬達安裝特徵的宿主可能為包住孔槽而擴框，需明示這個限制。
- 3D 的自動層距至少為本輪剛性件最大厚度加 2 mm，使厚板不因原 6 mm 層距穿插；不是完整干涉檢查。銷長應覆蓋相接板件厚度。
- 孔徑不再被機架樑寬暗中縮小；修改板寬時檢查孔邊留量，SVG／DXF 按鈕會攔下不足留量的桿板（包含稍後變更孔徑或匯入的作品）。這是基本尺寸檢查，不代表全部槽孔、干涉或加工條件合格。
- 窄畫面零件設定列保留直接復原入口；3D 收起任務卡，初始取景包括板件外形及爪端，而非只算孔位。

驗收 D1：T 拖曳／鍵盤／取消／一次復原，孔位不變且成對同步。
驗收 D2：桿／板寬 24 mm、厚 6 mm、材料標籤經 normalize、分享與還原一致；舊檔預設不變。
驗收 D3：同一件零件在 2D、3D 與 SVG／DXF 的輪廓一致；材料厚度寫入輸出註記；夾爪淨距依兩爪實際半寬相減，不再硬扣 18 mm。
驗收 D4：窄畫面實際操作與復原，其他零件／滑軌面板不殘留欄位；現有回歸測試通過。

本次不擴及齒輪、滑軌等採購件的材料選型，不新增碰撞、材料力學或機台加工參數。

## 後續功能必須遵守的六項交接提醒

以下 H1–H6 是每個工作包的開工與交付檢查表，不限於夾爪。施工順序與證據記在 [FTC-LOOP.md](FTC-LOOP.md)，不要另建重複規格。

1. **H1 孔位與外形分工。** 孔位決定運動，爪端／板寬決定實體外形；孔徑改變加工接口，不改孔心、孔距或 solver。若功能真的需要改變運動約束，另列規格及求解驗收，不借用外形操作暗中修改。
2. **H2 單一資料來源及相容性。** 桿板寬厚材料沿用元件 `stock`；新增資料要定義歸屬、缺省值與讀寫途徑。2D、3D、檔案、分享、匯出、製作記錄共用同一份值，禁止各自硬編預設或持有不同版本。讀取舊檔不得擅自改孔位或外形。
3. **H3 安全反悔。** 拖曳／輸入中是草稿，確認才提交；取消不改 snapshot 或自動存檔，一次有效操作只產生一筆復原。同值與無效輸入不留復原；左右同步整筆提交或整筆拒絕，不靠名稱猜通用配對。
4. **H4 優先沿用操作入口。** 先找畫布把手、尺寸線及既有零件／加工設定列。不得為每個新能力建立常駐面板、多層入口或重複設定；需要新面板時先說明現有入口為何不足，交回設計確認。
5. **H5 測試加實際操作。** 純函式與狀態測試不能替代瀏覽器驗收。實測窄畫面、選取切換、取消、一次復原、重載及輸出；下載內容測試與檔案實際落地分開記錄。更新中央 import map 的相關版本，避免新舊模組混用或產生第二份 state／view 單例。
6. **H6 不超出驗證證據。** 材料名稱不是強度認證，3D 疊層不是完整碰撞檢查，幾何可開合也不是可靠夾持或加工就緒。介面、錯誤訊息、記錄與交付說明都要保留這些邊界。

## R1e：孔徑／連接介面與加工設定隨作品保存（待施工）

狀態：本節是下一輪實作規格，尚未實作或驗收。基準版本為 R1d `4d2b5a6`。本次「建立 SDD／LOOP」只修改文件，不代表已開始施工、背景排程或 Git 提交。

### 目標與目前缺口

可操作成果：使用者在原加工設定內修改連接孔／既有馬達安裝尺寸，另存作品或分享給另一個環境後，取得相同的有效設定、零件孔槽與輸出；仍可一次復原，不必重新輸入本機偏好。

- 快速原型：沿用既有設定入口，換作品、重載或交接不必重設尺寸。
- 教學：能比較「改孔徑 → 孔槽／留料提示改變，但孔心與運動不變」。
- 數位樂高：作品帶著既有接口尺寸交換；尺寸相同不等於已驗證螺絲、配合或傳扭方式。
- 應用：同一新版作品不因接收端 localStorage 不同而輸出不同零件。

現況證據（R1d）：`settings.js` 的加工、TT、MG995 設定各自讀寫 localStorage；`schema.js` 的 `toSnapshot`／`normalizeSnapshot` 沒有帶這三組資料。`app.js` 的存檔、自存、分享、復原與製作記錄使用同一 snapshot 路徑，但啟動時先載入本機設定。因此不能僅新增一個 JSON 欄位就宣布閉環完成。

### 資料歸屬與範圍

保留作品外層 `kind: blocks`、`v: 1`，新增可選的頂層 `fabrication`。新版完整作品寫入下列形狀；`fabrication.v` 是加工設定自身的版本，與外層版本分開。

```text
fabrication
  v: 1
  export: { barWidthMm, holeDiameterMm, frameMarginMm, frameHoleDiameterMm,
            ttShaftFlatDiameterMm, ttShaftFlatThicknessMm }
  ttMount: { shaftDiameterMm, screwDiameterMm, screwOffsetXMm, screwSpacingMm,
             locatorDiameterMm, locatorOffsetXMm, locatorOffsetYMm }
  mg995Mount: { bodyLengthMm, bodyWidthMm, shaftOffsetMm, screwDiameterMm,
                screwSpanMm, screwSpacingMm, cableNotchWidthMm, cableNotchDepthMm }
```

- 以上為白名單，單位 mm；名字沿用現有設定，避免製造第二套名稱映射。`barWidthMm` 的 UI 名稱仍為「機架樑寬」，不覆寫元件 `stock.widthMm`。
- `stock`、齒輪已有的個別孔徑、馬達型別／安裝方向／宿主等元件資料仍留在原位置；本輪不搬移、不強制用全域值蓋過明確的元件值。各 consumer 現有個別值優先規則須列入測試。
- 活躍作品以 `S.fabrication` 作為唯一可變資料來源；設定 getter 是此物件的讀取入口。若舊 `S.*` 設定欄位須短期相容，只能做集中轉接，不能讓兩份可變設定分別驅動畫布與匯出。
- 純預設值、白名單正規化、版本檢查與修改計畫集中在不讀 DOM／localStorage 的模組；`settings.js` 保留表單與本機相容層，`app.js` 只接線。
- 本輪的「連接介面」僅指既有一般孔、TT 扁孔、TT／MG995 安裝孔槽及現有元件覆寫；不新增通用接口庫、自動配對、五金選型、公差、刀具補償、切削或列印參數。

### 載入、預設與舊檔策略

| 情境 | 有效設定來源與行為 |
| --- | --- |
| 新版 JSON／分享／自存有完整 `fabrication` | 以作品為準，不合併接收端偏好，不沿用前一作品。 |
| 新建空作品 | 可在建立當下複製合法的本機舊偏好；沒有偏好則用版本化內建預設。之後即是作品自己的設定，不保留動態繼承。 |
| 載入課堂範例 | 有隨附設定則用範例；沒有則用固定內建預設，避免受上一作品影響。 |
| 舊外部 JSON／分享沒有此欄位 | 使用固定內建預設；明示「舊作品未附加工設定，已套用預設，請核對孔徑」。不能推測作者當時本機值或宣稱完全重現舊加工輸出。 |
| 本機舊自存沒有此欄位 | 僅在啟動還原這份本機舊自存時，複製合法的本機舊偏好並提示已帶入；下次自存／存檔寫入完整設定。這個來源判斷由載入端傳入，不能讓 schema 自己讀 localStorage。 |
| `fabrication.v = 1` 但缺少已知欄位 | 缺項用該版本固定預設補齊並回報警告，不取本機值；下次保存為完整設定。 |
| 不支援的設定版本，或欄位型別／數值不合法 | 拒絕套用整份新作品並顯示原因，保留目前作品、復原及自存；不要默默退回預設後讓使用者誤以為已正確開啟。 |

額外約束：

- 開啟作品或修改作品設定不得覆寫跨作品的本機偏好；本輪不新增「設為全域預設」介面。舊 localStorage key 不刪除，保留相容與回復空間。
- version 1 的固定預設以基準版「清空偏好後，三組設定 loader 實際載入結果」為準並寫成測試 fixture，不能只抄 `state.js` 初始值。例如初始 state 的機架孔徑與 loader 缺省值可能不同，須以生效後的行為為準。
- 新增欄位不影響新版讀取舊作品；反向使用舊版程式時，它可能忽略 `fabrication`，因此不保證舊版能重現加工設定，須在交付說明註明。
- 未知欄位依白名單略過並警告；已知值採有限數字、現有合法範圍及小數精度。非法輸入不以 clamp 偷換為另一個可加工尺寸。跨欄位規則（如扁孔厚度小於外徑）須整組檢查。

### 操作與資料生命週期

1. 沿用原「加工設定」及 TT／MG995 設定控制項；用一行來源提示交代屬於目前作品或舊檔補值，不新增設定面板。
2. 原 `oninput` 不能再每打一字就提交作品。文字輸入保留草稿，以 change／blur／Enter 提交一次；Enter 隨後 blur 不得重複提交。Escape 取消；空白、未完成負號與無效值不改作品、自存或復原。
3. 有效且不同的設定先暫停，先保存一筆修改前完整 snapshot，再套用、重繪 2D／3D、更新製作記錄與自存。復原必須同步三組設定、零件／姿態與桌面／窄畫面表單。
4. 開啟另一份作品、範例或復原前取消未提交草稿；完整驗證新資料後才一次替換，避免新零件搭配舊孔徑的中間狀態。取消檔案選擇或讀檔失敗不修改現有資料。
5. 手動存檔、自動存檔、JSON 開啟、分享、undo snapshot、範例套用與 `gripperBuildRecord` 內嵌 JSON 全部走同一套收集／還原路徑，不在各呼叫點手動拼不同設定。
6. 幾何 consumer 只讀當前作品設定。2D 的接點點選符號可維持螢幕尺寸，但不能拿符號大小當實際孔徑；加工孔槽、3D 孔槽、SVG／DXF 必須相符。既有 3D 銷柱也不能被宣稱為已選型的五金。
7. 板寬不足、扁孔互斥尺寸等既有出口檢查不可退化；對「設定本身合法但目前零件不相容」顯示具體零件／欄位與修正方向並攔下加工匯出，不暗中放大板件、縮小孔或改運動。允許保存這種待修作品，重新開啟仍需顯示同一不相容原因。

### 驗收 E1–E8（全部待執行）

- **E1 正規化／版本：** 完整三組非預設設定 round-trip 不丟值；缺省、局部缺項、未知欄位、未知版本、空字串／null／布林／NaN／Infinity／超界與跨欄位衝突逐一測試。純函式不改輸入，也不讀瀏覽器儲存。
- **E2 跨環境重現：** A 使用孔徑 5 mm，B 的本機偏好為 8 mm；將 A 的新版作品經 JSON 與分享分別載入 B，必須仍為 5 mm，三組設定均一致，B 的偏好未被改寫。自存重載及製作記錄內嵌 JSON 也保留全部資料。
- **E3 舊檔／切換隔離：** 依上表驗證外部舊檔、本機舊自存、範例、新建空作品；A→B→舊檔→範例不得殘留 A 的加工設定。舊件無 `stock` 的 18／4 mm 缺省與孔心、爪端不變。
- **E4 草稿與復原：** 一次完整輸入只一筆復原；Escape／無效／同值無寫入，輸入途中自存不包含草稿；Enter＋blur 不重複提交。設定修改→改爪端→逐次復原時，幾何與三組設定均回到正確快照。
- **E5 幾何一致：** 各至少一個直桿、折線／結構板、夾爪、TT 扁孔輸出桿、TT 安裝宿主與 MG995 安裝宿主 fixture；核對實際孔槽、3D 與 SVG／DXF 位置／尺寸相同（比較幾何，允許弧線離散精度，不要求 SVG／DXF 文字逐字相同）。改孔徑不改 solver 孔心與角度結果；齒輪個別孔徑不被全域值蓋掉。
