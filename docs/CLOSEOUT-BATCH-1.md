### V6：匯出檔案

每類範例均從 UI 按下 SVG 及 DXF 匯出，下載檔已在磁碟確認，非僅依通知判定。

| 範例 | 每種格式的實際檔案 | UI 通知 |
|---|---|---|
| 齒輪 | GearA、GearB、frame | 2 個零件 + 機架 |
| 四連桿 | Link1、Link2、Link3、frame | 3 個零件 + 機架 |
| 滑塊曲柄 | Link1、Link2、frame | 2 個零件 + 機架 |

合計 20 檔：10 SVG + 10 DXF。SVG 通過 XML 解析且含幾何元素；DXF 通過群組碼／值配對、ENTITIES 與 EOF 檢查且含幾何實體；全部無 NaN／Infinity。這是檔案結構驗收，未在外部 CAD 或實際加工設備驗證。

不適用範圍：`exportLinksAsSvg`／`exportLinksAsDxf` 目前列舉 bar、plate、gear，並另匯出 frame。滑軌本體未納入；本批不新增滑軌製造輸出。blocks JSON 也不是舊版的 ARM `mechanism.json`，本批不驗收跨工具 ARM 匯入。

## 後續清單與未來功能

- 本批不承諾完成全部舊交接黃金流程（雙指 pinch、吸附合併、多馬達、手機完整互動等）；須分別記錄覆蓋範圍。
- draw/compile/solve 登錄表擴充與其他架構待辦屬未來工作，不因文件列有待辦就納入本批。
- **確認的非阻斷顯示問題**：1280×720 桌機初載齒輪對，部分齒輪外緣被畫布邊界裁切；本批仍可選取、編輯、播放與開 3D。下一批應檢查 fitView 是否納入完整零件輪廓及側欄可用寬度。
- **待驗證**：吸附合併、節點拖曳、雙指 pinch、手機／平板完整流程與全部範例互動。舊交接 input 驗收不能因此全部結案。
- **待驗證**：教學卡在復原、清空等其他作品切換路徑的生命週期；本批修正限於已重現的外部開檔路徑。
- **未來功能／產品決策**：若要開檔延續受控馬達播放角度，需另定作品格式與復原語意；若要完整製造滑軌，也需另外定義輸出規格。
