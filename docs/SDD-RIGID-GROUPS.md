# 剛性群組：設計／組立第一輪

沿用 Blocks 作品、板件輸出與既有六面固定接合。人與 AI 共用 `rigid-groups.js` 純操作；不增加求解器或第三種模式。

## 本輪範圍

- 設計各板 → 組立固定接合 → 建立剛性群組 → 選取整組 → 編輯群組／個別板 → 完成或解散。
- 單層群組以宿主的一個 bar／triangle 輸出構件為基準，納入接在此輸出及其下游機架面的純固定孔板。
- 翻斗基準是 LeftSide，成員是 Floor、RightSide、Back；宿主 Driver 的 Support 和 MG995 不整包納入。
- 不新增任何運動自由度。既有基準板的轉動與接合樹決定整組姿態；內部相對位置由六面固定接合決定。
- 只支援純 anchor 固定孔的附屬結構板。含馬達、滑塊或活動桿的子模組不納入。後續案例需要時才擴充可證明剛性的構件類型。

## 保存契約

模組選配 `rigidGroups: [{id,name,output,members:[moduleId]}]`。沒有群組的舊檔不補欄位。此欄位只是對既有剛性接合樹的命名與操作邊界，不保存第二套變換矩陣。

正規化限制名稱、數量、識別字及重複項；檢查時確認基準構件、固定板、六面接合與連通性。拆下或結構變更造成無效群組時顯示警示，不能當作仍然有效；可解散後重新成組。

建立／解散各走既有一次復原與保存。解散只移除群組，不拆下板件。單件加工資料及接合孔沿用原輸出。

## 界限

本輪不提供將混有活動支架的宿主整包抽離、複製、跨作品重新安裝或巢狀群組；外部驅動介面仍是既有輸出端。群組不代表角碼承載、干涉、材料強度或實物已驗證。編輯群組是既有板件設計與接合操作入口，不另造 CAD 編輯器。

## 驗收

翻斗四板成組且支架不動；拒絕活動子模組／斷接／循環；成組前後多姿態材料模型完全一致；解散保留幾何接合；保存與分享重開保留資料；瀏覽器實操建立、選取、編輯、解散及復原。手機入口不增加畫布常駐教學卡。
