本索引涵蓋 Git 追蹤的 Markdown 文件（包含根目錄與 `.agent`），不收錄未追蹤草稿、輸出截圖及暫存資料。分類是閱讀用途，不代表規格全部已實作；完成程度以文件內狀態和相應驗收證據為準。歷史紀錄不覆蓋現行契約，舊版 mechanism 仍為凍結查考。

新增、移動或刪除文件時同步更新此索引。規格寫契約；現況頁保持精簡；詳細進度與驗收寫入工作／更新紀錄，避免在多份文件重複維護狀態。
