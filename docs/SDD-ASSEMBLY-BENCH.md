# SDD — 組立台（把做好的模組「方便地」組起來並測試）

> 上位文件：[SDD-ASSEMBLY-MODULES.md](SDD-ASSEMBLY-MODULES.md)（模組、安裝、各自求解）、[SDD-ORTHOGONAL-MOUNT.md](SDD-ORTHOGONAL-MOUNT.md)（直角安裝、轉接座）。
> 施工記錄寫在 [FTC-LOOP.md](FTC-LOOP.md)。狀態：**B1～B7、C1～C3 已完成（2026-10-02）**。接口：輸出端（同平面）、桿的邊、三角板的邊、未安裝模組機架板的邊（直角），宿主可在任一平面；組合積木可匯出 JSON。未做：已安裝模組的機架板邊、子模組「立在面上」（child-edge）接法、任意角度。

## 0. 一句話

「設計台」做單一機構，「組立台」把做好的模組像樂高一樣接起來：在 3D 裡點接口、吸上去、一鍵轉向翻面、沿邊滑動，接好立刻跑全行程測試，撞到的零件變紅；組好的結果直接產生轉接座、孔位與製作包。

## 1. 現況與缺口

| 項目 | 現況（O1～O7） | 缺口 |
| --- | --- | --- |
| 接口 | 輸出端要寫在模組裡；可直角安裝的邊只有內建四連桿有（程式寫死） | 學生自己做的模組沒有辦法標「這裡可以接」 |
| 擺放 | 直角安裝的方向由「base→重心」自動猜；同平面靠 2D 拖把手 | 不能轉向、翻面（直角）、沿邊挪位置 |
| 操作 | 2D 一次一個平面；3D 只能看 | 看不到也調不到兩個平面的相對關係 |
| 測試 | 干涉只出現在製作包文字 | 組的當下看不到哪裡會撞、在幾度撞 |
| 重用 | 組好的作品只能整份存 | 不能把「升降＋夾爪」存成一個新積木 |

## 2. 使用者流程（目標）

1. **設計台**：照舊做「四連桿升降臂」「齒輪夾爪」，各自播放測試。
2. 按「🧩 組立台」：畫面切成 3D，左側列出作品裡的模組（含模組庫可拖入），右側是「接法面板」。
3. **接**（兩種都要有，手機與電腦都好用）：
   - **點兩下**：點宿主上一個發亮的接口 → 再點子模組上一個接口 → 預覽（半透明）→ 按「接上」。
   - **拖吸附**：拖子模組靠近，相容的接口發亮，進入吸附範圍就吸上並顯示預覽，放開即接。
4. **調**（預覽或接好後都能調，每一步一個大按鈕、可復原）：
   - 「↻ 轉 90°」：繞接合線轉（同平面↔直角，或直角的另一個方向）。
   - 「⇄ 翻面」：換到宿主的另一面。
   - 「◀ ▶ 沿邊」：沿接合線一格一格滑（一格＝5 mm，或孔距）。
   - 「⟲ 掉頭」：子模組前後反過來（爪朝前／朝後）。
5. **測**：按「▶ 全行程測試」：每顆馬達依序跑完整行程，撞到的零件即時變紅，下方時間軸標出撞的角度，點一下跳到那個姿勢；沒撞就顯示綠勾。
6. **做**：「製作包」「轉接座 STL」「DXF」直接用組立台的結果。
7. **存**：「存成組合積木」→ 進模組庫，下次整組插入（例如「升降夾爪組」）。
8. 在組立台雙擊某個模組 → 回設計台編輯那個模組（它自己的平面）。

## 3. 方便組立的設計原則

- **接口先行、自動提示**：每個模組自動產生候選接口（§4），學生不必先懂「輸出端」才能組；進階再手動增刪。
- **只亮相容的**：拿著夾爪時，只有能接夾爪的接口發亮；接口旁顯示預覽小圖示（同平面／直角）。
- **預設就合理**：吸上時自動選最常見的姿勢——直角時子模組「遠離宿主、爪朝外」，同平面時對齊孔距；需要才調。
- **一步一鍵、看得到結果**：轉向、翻面、滑動都是按鈕（手機不靠多指手勢），每一步立刻更新 3D 與干涉顏色。
- **錯了好回頭**：每次接、調都只記一筆復原；「拆下」把子模組放回原位，不丟零件。
- **限制講白話**：不能接時說原因（「這條邊只有 24 mm，夾爪需要至少 20 mm 的接合長度」「兩個模組會形成環」）。

## 4. 接口模型（ports）

每個模組的接口由兩個來源合併：

1. **自動接口**（不存檔，每次由零件算出）：
   - 剛體構件（桿、板、齒條）的兩條長邊 → `edge` 接口（可直角）。
   - 剛體構件上兩個以上、間距固定的孔 → `bolt` 接口（同平面對鎖，沿用 bolts）。
   - 模組底板（`<id>-frame`）外框的邊 → 子模組用的 `edge` 接口（直角時「站」在宿主上的那一邊）。
   - 範圍：只取「輸出端構件」與「底板」，避免整台機器亮成一片。
2. **手動接口**（存在模組 `ports[]`）：學生或老師加的、改名的、隱藏的。

```jsonc
"ports": [
  { "id": "toolBottom", "name": "工具架下緣", "kind": "edge", "body": { "kind": "bar", "id": "ToolBrace" }, "side": -1 },
  { "id": "carriage", "name": "滑台", "kind": "bolt", "body": { "kind": "rack", "id": "LiftRackGear" }, "holes": ["LiftOutput", "LiftOutputB"] },
  { "id": "baseTop", "name": "底板上緣", "kind": "edge", "body": { "kind": "frame" }, "edge": 2 }
]
```

既有 `outputs`（含 `orthogonal: {side}`）在讀檔時轉成等價的 ports，舊檔不變。

## 5. 連接模型（mount v2）

```jsonc
"mount": {
  "to": { "module": "Lift1", "port": "toolBottom" },
  "from": { "port": "baseTop" },          // 子模組用哪個接口
  "angle": 90,                             // 0＝同平面；90＝直角（O1 的 orient）
  "side": -1,                              // 宿主哪一面
  "offsetMm": 10,                          // 沿接合線的位置（從接口中點起算，格點 5 mm）
  "reverse": false,                        // 子模組前後掉頭
  "flip": false,                           // 子模組疊層反過來（L7）
  "joint": { "kind": "printed", "wallMm": 4, "holesPerFlange": 2 }   // 直角才有
}
```

- 同平面（angle 0）沿用 D1 剛體變換；直角（angle 90）沿用 O1～O6 的 `orthogonalFrame`，多了 `offsetMm`、`reverse`、子模組接口邊。
- 既有 `mount.orient` 讀檔時轉成 v2；寫檔用 v2（版本欄位 +1，舊版 app 讀到會顯示「需要新版」）。

## 6. 測試（全行程）

- 沿用連續求解（O7）與 interference（同層、螺絲頭、隔柱、MG995 機身、跨平面）。
- 新增「即時模式」：播放或拖到某個姿勢時，只檢查目前姿勢（快），把撞到的零件在 3D 變紅、2D 加紅框。
- 「全行程測試」：依序掃每顆馬達，結果做成時間軸（馬達 × 角度），點擊跳到該姿勢。
- 效能目標：四連桿＋夾爪全行程 < 1 秒（桌機）。

## 8. 使用者決定（2026-10-01）

- **Q1 位置**：獨立模式，上方切換「設計／組立」，組立以 3D 為主。
- **Q2 裝置**：手機、平板、電腦都要——「點兩下接」與「拖曳吸附」兩種都做，按鈕要大。
- **Q3 沿邊滑動**：一格 5 mm。
- **Q4 組合積木**：要（B7）。

## 9. 不做（本輪）

- 任意角度（只做 0° 與 90°）、雙側板夾持、跨模組閉環。
- 力學（扭力、懸臂彎曲）。
- 改 svg2gcode。
