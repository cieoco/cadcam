# 固定與動力支撐檢查（2026-10-11）

## 目的與邊界

固定支點讓求解器有基準，不代表已畫出可製作的底座。現有單軸翻斗已有 Support 固定桿及 Drive.motorMount.frameBody 宣告，不能僅憑遮蔽的畫面判定無支架。此輪核對宣告及固定／活動件關係，不新增存檔格式、不另寫求解器，也不偽造已驗證的螺絲或軸承。

## 共用介面

validateSupports(snapshot) 為純函式，供 UI、行程與翻斗共同操作使用。回傳 ok（宣告無錯誤）、status、physicalVerified、fixedPoints、motors、issues 及 scope。即使宣告有效，physicalVerified 仍為 false。固定支點標記 ideal_fixed；固定支架標記 fixed_frame_declared；隨動機架僅標記 moving_carrier_declared。

錯誤：指定機架不存在、機架與輸出同一元件或共用兩個剛性主孔、非固定機架未宣告隨動、輸出或中心引用錯誤。非錯誤但未驗證：省略實體機架、隨動或跨模組支撐、模組固定基準至底座鏈、鎖固／承載／另一側軸支撐。另一側支撐的必要性依負載與外購件規格判定，不能一律視為缺件錯誤。

## 呈現與驗收

可運動狀態改稱「可模擬｜實體固定待驗證」。組立面板以可展開區塊列出診斷與目標件；不把干涉通過當成安裝通過。行程報告附 support，明確錯誤會拒絕任務候選。

測試包含翻斗原件、刪除 Support、浮動機架、機架與輸出同體、兩孔同體、退化固定桿、未指定支架、錯誤軸心／輸出引用、不修改來源，以及共同教學入口；另跑原有翻斗與行程回歸、瀏覽器確認 UI。

後續才以可測量的安裝孔、實際支架與接合證據提升驗證等級；本輪不宣稱已完成實體支撐設計。
