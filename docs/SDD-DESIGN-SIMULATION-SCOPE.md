# 設計分頁的模擬隔離（2026-10-12）

## 問題與契約

`blocks (34).json` 同時含四板翻斗與未命名四連桿。原畫面只顯示目前分頁，求解、播放任務閘門與狀態卻讀全部零件，造成翻斗的單一結構契約拒絕無關的四連桿。

- 設計模式以 `compsInFocus` 選取同一份可見零件，獨立編譯及求解；不將其他頁的馬達、無解、行程或任務限制套入本頁。
- 播放、軌跡、錄影共用這個求解範圍；固定孔距與求解失敗防護保留。
- 切頁沿用暫停與馬達角度保存，另清除上一頁連續解種子和軌跡快取。
- 組立模式仍使用完整 `compileAssembly`／`solveAssembly` 和既有任務契約。
- 有模組時，單頁一般模擬不宣稱整份翻斗／升降教學任務已驗證；完整任務限制保留於組立。沒有模組的原教學作品維持原行為。
- 不改存檔、孔距、組立關係、刪除保護與共用 solver。尚未支援的混合組立任務仍如實拒絕，不假裝通過。

## 驗收

- `test/simulation-scope.mjs`：保留使用者機構回歸資料；四根桿可在局部可達區間求解，逐點核對孔距；隱藏模組無效不影響本頁；組立仍讀全部。
- `test/motor-tools.mjs`：局部範圍不得借用隱藏伺服行程。
- `test/design-isolation.html`：桌面及手機尺寸，各 25 項實際瀏覽器操作通過；包含播放實際桿件更新、切頁暫停、無動力頁拒絕播放、馬達切換，以及組立保留原拒絕行為。
- 使用者四連桿的兩活動臂為 80 mm，但固定桿 112 mm、連接桿約 108.229 mm，並非精確平行四邊形。保留自動往復擺動範圍，不承諾連續整圈旋轉。
