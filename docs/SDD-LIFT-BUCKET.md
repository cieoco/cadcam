# 平行升降托斗 SDD

沿用平行四連桿五零件範例與四板料斗，以群組安裝純操作建立單馬達整合案例。料斗水平保持，沿圓弧升降；本輪沒有翻轉自由度。

- 輸入：兩臂共同長度、C 相對 A 起終高度；沿用原任務卡與候選／確認／取消。
- 組立：Lift 的 Link3 在 C 提供輸出；料斗獨立基準板掛在該輸出，保留三個內部板面接合。
- 共用驗證：原平行升降高度／等長／分支檢查；另以真實材料姿態取樣確認四板方向保持、相對位置不變、位置跟隨 C。拆下則不宣稱跟隨。
- 反例：不等長、不可達高度、錯誤輸出端、斷開內部板、循環、修改後接合未刷新。
- 保存、分享、復原沿用 snapshot；不新增求解器或依賴。
- 僅為運動組立示範。連接孔與五金匹配、承載、全行程干涉、加工就緒尚未核對。

## 完成與已知限制

本輪完成運動／群組整合，證據见 WORK-LIFT-BUCKET-2026-10-10.md。3D已檢出此配置板件干涉，UI與教程明列不可直接加工；後續實體安裝需空間避讓及五金核對，不能以本輪運動通過代替。

## 分層避讓（2026-10-10，v2026.10.10.10）

原同層安裝已檢出穿透。本輪改用既有六面接合：Link3 top → LeftSide bottom，對準基準孔的XY投影，預設板面間距12mm。此為空間配置，不是已核對的間隔柱／螺絲總成；外部接合尚未生成實物五金。

共用固定安裝端檢查新增「p1/p2固定且無驅動的多孔板」。選面、接合描述、保存與3D材料姿態採同一規則；多孔板找不到材料時不得回退為零高度。內部三片板與角碼接合不變。

剛性群組拆下保留內部接合，重裝可輸入0–50mm板面間距。升降托斗安裝候選在確認前跑既有任務與材料採樣；干涉／資料缺失回傳失敗，不修改作品。舊同層作品仍可讀，但需重新安裝才能通過避讓檢查。

材料採樣最多5度，與主孔0.5度掃描分開列示；回歸另用32/64/120mm臂、0–80度每2度共123點。6mm在120mm臂高位會穿透，保留反例。連續行程、馬達與軸銷接觸、鎖固與承載均未驗證。
