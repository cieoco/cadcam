# 平行升降托斗 SDD

沿用平行四連桿五零件範例與四板料斗，以群組安裝純操作建立單馬達整合案例。料斗水平保持，沿圓弧升降；本輪沒有翻轉自由度。

- 輸入：兩臂共同長度、C 相對 A 起終高度；沿用原任務卡與候選／確認／取消。
- 組立：Lift 的 Link3 在 C 提供輸出；料斗獨立基準板掛在該輸出，保留三個內部板面接合。
- 共用驗證：原平行升降高度／等長／分支檢查；另以真實材料姿態取樣確認四板方向保持、相對位置不變、位置跟隨 C。拆下則不宣稱跟隨。
- 反例：不等長、不可達高度、錯誤輸出端、斷開內部板、循環、修改後接合未刷新。
- 保存、分享、復原沿用 snapshot；不新增求解器或依賴。
- 僅為運動組立示範。連接孔與五金匹配、承載、全行程干涉、加工就緒尚未核對。
