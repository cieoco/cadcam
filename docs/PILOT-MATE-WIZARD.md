# 試行記錄 — 接合精靈：齒條升降 ← 四連桿升降臂 ← 齒輪夾爪

> 日期：2026-10-07，版本 2026.10.07.6。規格：[SDD-MATE-FACES.md](SDD-MATE-FACES.md)。施工記錄：[FTC-LOOP.md](FTC-LOOP.md)。
> 目的：用手機尺寸（390×844）把三個內建機構從設計一路走到製作包，人工核對製作包，找出還做不出來的地方。這是軟體內的試行，**尚未實際切割與組裝**。

## 1. 流程（真實觸控操作，無 console error）

1. 設計：從模組庫插入「齒條升降」「四連桿升降臂」「齒輪夾爪」，各自一個分頁；接合面用內建預標的（齒條＝滑台；四連桿＝工具架上緣、下緣；夾爪＝安裝方向 90°）。
2. 組立：清單顯示齒條升降為底座，另外兩個未安裝。
3. 點「四連桿升降臂」→ 卡片「齒條升降・滑台（平貼對鎖）」→ 預覽沒有干涉 → 接上。
4. 點「齒輪夾爪」→ 卡片「四連桿升降臂・工具架下緣（角碼直角）」→ 預覽沒有干涉 → 接上。
5. 清單變成三層（深度 0／1／2），沒有未安裝。
6. 全行程測試 → 下載製作包。

## 3. 試行發現

1. **四連桿的搖臂沒有辦法固定在伺服舵盤上（開工前就存在）。** 搖臂（LiftCrank）在馬達軸位置只有一個 3.2 mm 孔，沒有舵盤螺絲孔；舵盤孔樣式目前只會加在齒輪上。製作包因此少了這顆伺服的 4 顆舵盤螺絲，組裝步驟也沒有「把搖臂鎖到舵盤」。照現在的檔案切出來，搖臂會空轉。**這是實作前必須補的。**
2. **這個組合在齒條行程低處會撞。** 馬達 1 在 −112°～−82° 時，四連桿的伺服機身會撞到齒條升降的機架板與小齒輪。軟體有偵測到並建議把齒條長槽縮短 17.4 mm（行程改為 −79°～112°）。這是設計回饋，不是軟體錯誤；套用限位後需重跑。
3. **組立教學單元的同平面練習不在精靈裡。** 教學用的「平行四連桿升降臂」工具架輸出端只有 1 個點，同平面對鎖做不出孔位，精靈依規則不列出；教材已改為請學生按「進階（工程模式）」完成該練習，延伸活動改用精靈的角碼直角。若要讓同平面對鎖也能做出來，需要新增「桿件上的對鎖孔」（在桿上指定兩個固定孔）。
4. 已安裝模組的馬達軸（例如四連桿的 O1）不會出現在製作包「馬達軸要墊高」的提示裡，因為已安裝模組的底板不含基準點。影響說明完整度，不影響孔位。
5. 製作包的檔名仍是內部名稱（`Mod2-frame.dxf`）；畫面上的干涉訊息已改成「四連桿升降臂的底板」這類名稱，製作包因為要對得上 DXF 檔名而沒有改。
6. 80 mm 的工具架實際只排得下 2 個角碼接合（第一個固定在中間，不會自動重排）。

## 4. 還沒驗證的事

- 實際切割、鑽孔、鎖角碼（M3×6 鎖進 1.2 mm 螺牙）的強度與垂直度。
- 角碼實際尺寸（孔心離末端 3.5 mm 為假設值）、TT 輪轂與 MG995 舵盤孔位。
- 接在未安裝機構上的子組件，在接到底座前不檢查干涉。

## 5. 建議的下一步

1. 補「桿件接伺服舵盤」的孔位與五金（發現 1）。
2. 新增「桿件上的對鎖孔」，讓同平面對鎖可製作，教學單元即可回到精靈（發現 3）。
3. 實際切一組（底座＋升降臂＋夾爪）驗證角碼接合。
