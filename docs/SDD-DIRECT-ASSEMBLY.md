# 直接組裝操作規則（快速原型）

目標：使用者能在既有畫布上，以最少步驟完成「放零件 → 接孔 → 修改 → 播放」。優先改善操作，不增加常駐教學介面。

## 第一輪：二孔連桿

- 零件盤的「連桿」啟動二孔繪製；桌機可按住起點拖到終點放開，也可點兩下。觸控以拖放完成。
- 起點或終點靠近既有可見孔時，以畫面上的孔位吸附，並共用該接點 ID。終點吸附時以兩孔實際距離記錄桿長；自由終點維持 8 mm 孔距。
- 吸附預覽直接畫在目標孔上，放手前就能判斷是否會連接。
- 多孔桿／板另用「多孔板」入口，維持逐孔放置與既有編輯能力。
- 點另一種繪圖工具直接切換；再次點目前工具才取消。
- 狀態列先說明下一個可做動作；自由度數值保留在滑鼠提示。沒有零件或動力時，播放鍵直接說明缺少什麼。
- 分享連結與本機存檔優先於空白初始狀態；原有資料讀取規則不變。

## 驗收情境

1. 空白畫布選連桿，從空白處拖出，放開後得到一根二孔連桿。
2. 從既有孔拖到另一個既有孔，放開後新連桿與兩端共用接點；無須再拖端點合併。
3. 只靠近終點孔時，只接終點；自由端長度仍對齊 8 mm。
4. 多孔板仍可繪製、存檔、載入與編輯；滑軌與馬達流程不受影響。
5. 無動力時按播放不進入播放狀態，並提示放置動力來源。

每輪檢查上述情境，再依實際卡點調整。若需要新的產品取捨，先展示可操作結果再討論。
