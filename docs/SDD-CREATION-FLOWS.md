# 新增與修改操作流程（2026-10-11）

目標：同一編輯器服務空白建立與範例修改，不新增作品模式或求解器。

| 情境 | 起始呈現 | 操作 |
| --- | --- | --- |
| 空白作品／空白設計分頁 | 新增展開 | 固定支點、連桿、板件，或加入模組 → 接合與動力 → 播放與檢查 |
| 範例／開啟已有作品 | 新增收合 | 觀察播放 → 暫停點選零件 → 改尺寸 → 重新檢查；需要改造再展開新增 |
| 組立 | 保留既有結構清單 | 選取、接合、拆下、群組 |

本輪：新增入口可隨時展開／收合；傳動與加入模組分別收納；「多孔連接板」入口更名「板件」，保留既有逐孔繪製能力，不宣稱任意CAD加工。固定支點提示為理想模擬約束。繪製連桿／滑軌／板件時有明確取消入口。桌面入口收合讓出畫布；手機新增區限高且可捲動。

狀態規則：新作品或切換分頁依該分頁是否空白決定展開；新增第一個零件後不強制收合，也不於播放／普通尺寸修改覆蓋手動選擇。復原仍走原資料流程。收合不修改或刪除作品；取消僅退出現有繪製工具，不新增復原記錄。

手機底部「新增」為明確使用意圖，直接展開；初次重開或載入範例不套用這項強制展開。取消按鈕固定在新增捲動區底部，避免模組展開後掉到畫面外。

驗收：空白→新增→取消；範例→收合→展開改造；分頁切換；桌面與手機工具可達且無水平溢出；保存／復原、檢查與AI契約保持原有規則。長期統一動力安裝引導與設定面板另行逐步處理，不在此輪重寫。
