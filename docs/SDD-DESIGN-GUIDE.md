# 設計引導（第一輪）

目標：在既有設計／組立介面提供可收合的下一步提示，不另建作品格式或強迫操作順序。

流程：先想預期輸出 → 畫骨架 → 定機架 → 選驅動 → 試播檢查 → 組立與實作。

## 契約

- 僅依目前設計分頁的零件判斷提示；不以其他分頁的固定孔、馬達宣告本頁已完成。
- 空白頁引導畫桿；只有固定點仍需建立活動零件。
- 使用者可選兩點桿或三點板設為機架，固定其孔位；選單一孔則只固定該孔。動力零件不得透過此捷徑默默移除馬達。
- 固定命令保留目前顯示座標與尺寸，記錄一次復原，沿用現有保存／重建流程。
- 選驅動沿用既有 TT／MG995 放置、輸出桿與機架選擇流程。
- 有固定點不代表機架完整，有驅動不代表可動或行程已驗證。試播沿用原有驗證，不能繞過。
- 不自行標記曲柄／搖桿、不推論加工就緒；手機不新增常駐資訊列。

## 驗收

提示涵蓋空白、只有固定點、有桿無固定、有固定無驅動、有驅動；本頁隔離。
機架候選保持原物件與尺寸、拒絕已有動力、只變更所選零件的共用孔角色。
瀏覽器檢查桌面／手機入口、動作入口與復原。

## 本輪實作與驗收（2026-10-12）

- 已加入頂列可收合「設計引導」，沿用原畫布與動力選單；提示依當前設計更新。
- 實測自由桿設為機架後仍為 80 mm，一次復原回自由桿；全固定結構提示先新增活動桿。
- 手機 390 × 844 下完成固定單孔、選 MG995、放到固定軸心、試播；重開後仍進入試播提示。
- 引導開啟時未造成橫向溢出；收合後不佔畫布空間。瀏覽器未回報 console error。
- 這是操作提示與機架捷徑，不是自動機構綜合、完整機架驗證或曲柄／搖桿分類器。
