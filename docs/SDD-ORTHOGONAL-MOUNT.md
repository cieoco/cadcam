# SDD — 直角安裝（模組裝在互相垂直的平面上）

> 上位文件：[SDD-ASSEMBLY-MODULES.md](SDD-ASSEMBLY-MODULES.md)（模組、安裝、D1 各自求解＋剛體變換）。
> 試行路徑：「競賽四連桿升降臂＋齒輪夾爪」。舉升＋夾取（同平面）已走通，見 [FTC-LOOP.md](FTC-LOOP.md) L1～L7。
> 本文件只定義行為、資料契約與驗收；施工記錄寫在 FTC-LOOP.md。狀態：**O0～O6 已完成（2026-10-01），v1 只支援宿主邊（edge: 'host'）**；子邊、任意角度、雙側板見 §7。

## 0. 一句話

讓一個模組（例如夾爪）用 90° 裝到另一個模組（例如四連桿升降臂的工具架）上：兩邊各在自己的平面上設計與運動，軟體負責算出整體位置、畫出側影、切出接合特徵、列出五金與組裝步驟，並檢查直角方向的干涉。

## 1. 為什麼是新議題

目前所有模組都疊在**同一個平面**：零件是一層層 3 mm 板，安裝＝在平面內平移／旋轉（D1），疊層與干涉都以「平面＋層號」計算。

四連桿升降臂是**側視**機構（手臂在垂直面上擺），夾爪是**正視／俯視**機構（兩爪左右開合）。實物上夾爪的平面與手臂的平面互相垂直，現有模型表達不出來：

| 面向 | 同平面安裝（現況） | 直角安裝（缺口） |
| --- | --- | --- |
| 位置 | 2D 剛體變換 (x, y, a) | 要 3D 位姿：子模組平面繞接合線轉 90° |
| 畫面 | 同一張圖 | 宿主圖裡子模組只剩一條「側影」；子模組要在自己的平面編輯 |
| 求解 | 已是各自求解（D1） | 不變：子模組在自己的平面解，宿主只決定它整塊的位姿 |
| 疊層 | 一條層號軸 | 兩條疊層軸互相垂直，各算各的 |
| 接合 | 對鎖螺絲穿過兩片板 | 板的「邊」靠在另一片板的「面」上，要角碼或榫槽 |
| 干涉 | 平面 SAT＋層號 | 子模組在宿主圖裡是一塊有厚度的帶狀體，要跟宿主那一側的零件比 |
| 3D 檢視 | 目前不認得模組（`blocks3d` 沒有 moduleId） | 要畫出轉 90° 的子模組 |

## 2. 物理模型：T 形接合

兩片板直角相接時，一定是**一片板的邊靠在另一片板的面上**，接觸線同時在兩片板的平面內：

- **子邊（edge: 'child'）**：子模組底板的一條邊立在宿主構件的面上。例：夾爪底板垂直立在工具架板面上。
- **宿主邊（edge: 'host'）**：宿主構件的一條邊壓在子模組底板的面上。例：工具架下緣（ToolBrace）壓在水平夾爪底板的中線上，夾爪吊在手臂下方、爪朝前。

接觸線在宿主平面裡是線段 `hostLine`（在宿主構件座標），在子模組平面裡是線段 `childLine`（在子模組座標）。兩條線重合、方向一致；子模組平面繞這條線站起來，朝宿主平面的哪一面（正面＋n 或背面－n）由 `side` 決定。

試行路徑的姿勢（§6 Q2 已決定）：**宿主邊**，工具架下緣壓在夾爪底板中線，夾爪水平、爪朝前、左右開合。

## 3. 決策（草案）

- **O-D1 子模組座標存在自己的平面。** 直角安裝的子模組，零件座標＝子模組自己平面上的座標，跟宿主怎麼動無關；不像同平面安裝要存 home 世界座標並 rebake（ASSEMBLY D3）。現有 2D 編輯器全部沿用。
- **O-D2 求解不變。** 子模組照 D1 各自求解；宿主只提供「接合構件」當下的位姿，乘上直角轉換得到子模組平面在 3D 的位姿。solver 不改。
- **O-D3 視圖切換。** 主畫面一次只畫一個平面：預設畫根平面（宿主），直角子模組畫成側影帶（§4.3）；模組面板「編輯此模組（正視）」切到子模組平面，宿主改畫成側影。播放時兩邊照常動。
- **O-D4 疊層分開算。** 每個平面各自一條疊層軸（沿用 build-plan 的層與隔圈）；子模組的疊層高度決定它在宿主圖裡側影帶的寬度。
- **O-D5 接合用 3D 列印轉接座（§6 Q1 已決定）。** 3 mm 木板的邊太薄，鎖不了 M3（T 形螺帽槽在 3 mm 板上沒有肉），所以不採板邊攻牙。軟體依接合線產生一個 L 形轉接座（兩翼各貼一片板，壁厚預設 4 mm，長＝接觸長度，每翼 2 個 M3 穿孔），匯出 STL 給 3D 印表機；兩片木板只需要在對應位置鑽 3.2 孔，M3 螺絲穿過板與轉接座、鎖防鬆螺帽。轉接座尺寸先用常見值，之後實物再調。
- **O-D6 樹狀不變。** 直角安裝仍是一個安裝接口，不允許跨平面閉環。
- **O-D7 一次只支援 90°。** 任意角度、雙側板夾持（手臂兩片側板夾住工具）列為後續。

## 4. 資料契約

### 4.1 mount 新欄位（選配；沒有就是同平面安裝，舊檔不變）

```jsonc
"mount": {
  "to": { "module": "Lift1", "output": "tool" },
  "ref": { "x": 0, "y": 0, "a": 0 },          // 同平面安裝才用；直角安裝存 0
  "home": {},
  "orient": {
    "type": "orthogonal",
    "edge": "host",                           // 'host'｜'child'：哪一片板的邊靠在另一片的面上
    "hostLine": [ {"x": -24, "y": -1.5}, {"x": 24, "y": -1.5} ],   // 宿主接合構件座標（mm）
    "childLine": [ {"x": 0, "y": -40}, {"x": 0, "y": 40} ],        // 子模組座標（mm）
    "side": 1,                                // +1＝宿主正面那側，-1＝背面
    "joint": { "kind": "printed", "wallMm": 4, "holesPerFlange": 2 }  // 3D 列印 L 形轉接座（§6 Q1）
  }
}
```

- 輸出端 `outputs[].body` 必須是剛體構件（桿、板、齒條）；直角安裝的 `hostLine` 存在該構件座標，跟著構件動。
- `hostLine` 與 `childLine` 長度不同時，接觸長度取兩者重疊部分；長度 < 20 mm 給警告（太短不穩）。

### 4.2 模組輸出端標記可直角安裝

`outputs[].orthogonal: { lines: [...] }`（選配）：宿主作者預先標好可直角安裝的邊或面線，插入時讓使用者選。四連桿升降臂內建模組要標工具架下緣與前緣。

### 4.3 側影帶

在宿主平面，子模組投影成一條帶：長＝子模組沿接合線方向的範圍，寬＝子模組疊層總高（含隔圈），位置在接合線的 `side` 側。畫成斜線填色加名稱「齒輪夾爪（側影）」，可點選（選到＝選到該模組）。反過來，在子模組視圖裡宿主也畫成側影帶。

## 6. 使用者決定（2026-10-01）

- **Q1 直角接合**：3D 列印轉接座（見 O-D5）。
- **Q2 夾爪姿勢**：水平、爪朝前，吊在工具架下方（宿主邊）。
- **Q3 馬達數**：拿掉四連桿的手腕馬達，靠平行四連桿讓工具架保持水平；M1 升降＋M2 夾爪（MG995）。
- **Q4 手臂側板**：先用單片手臂。雙側板夾持列為後續。

## 7. 不做（本輪）

- 任意角度安裝、球面／萬向接頭。
- 跨平面閉環（例如夾爪連桿又接回手臂）。
- 力學（夾持力、懸臂彎曲）。
- 改 svg2gcode（使用者決定先不動）。
