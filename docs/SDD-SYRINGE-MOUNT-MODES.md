# 針筒固定環與承載板：固定／可轉安裝

## 需求與邊界

固定關係拆成「筒身夾在固定環中」及「固定環接到承載板」。兩者用同一個雙耳固定環：兩耳都鎖限制方向；只鎖一耳時，那顆耳螺絲成為轉軸，容許筒身與固定環一起繞垂直板面的軸轉動（螺絲離筒身軸線 14 mm，即 28 mm 耳距的一半）。共用圓盤、固定桿及固定板件的材料幾何，不另建求解器。

第一版兩者均接固定機架，推桿連接一般兩孔桿／圓盤的端孔。可轉式直接驅動具有固定軸的輸出件；不自動刪除固定式原有短連桿，也不為欠約束結構補隱藏固定點。使用者須改接或使用 H08 比較範例。活動承載件、任意轉軸方向與通用多自由度機構不在本輪。

## 資料與共同規則

- 保留 `mountMode:'fixed-axis'` 的既有語意，新增 `mountMode:'pivot'`。未帶 mode 的歷史兩端鉸接檔仍照舊處理，作品版本保持 1。
- 固定式：`a` 是固定環中心／安裝基準。可轉式：`a` 是鎖住的那顆耳螺絲（轉軸），新增 `pivotEar`（+1＝沿推進方向看的左耳，−1＝右耳，預設 +1）。`b` 是推桿接孔，皆為承載件局部座標。固定式保留 `axisDeg` 與短桿輸出鏈；可轉式不保存固定方向，也不沿用舊 `outputId`／夾爪特例。
- 可轉式運動學：推桿端 B 在筒身軸線上，離固定環中心的軸向距離 L = `lmin` + 伸出量；轉軸 A 偏離軸線 14 mm，所以 A–B 距離 = √(L² + 14²)（`expandSyringes` 以此建立距離約束，`validateSyringePose` 以此算殘差）。筒身軸線方向 = A→B 方向再依 `pivotEar` 轉 ±atan(14/L)；`syringeShape` 的 `angle`／`length`／`a` 是軸線角度、軸向長度與固定環中心，另附 `anchor`（A）、`pivotEar`、`lockedFoot`。力臂用筒身軸線（過 B）量，不是 A–B 連線。
- 舊存檔（可轉式沒有 `pivotEar`）讀入時補 `pivotEar:1`，並把 `lmin` 換成軸向長度，使 √((lmin+伸出量)²+14²) 等於舊的 A–B 距離，原姿勢保留。
- `installation.face`、`spacerMm` 共用；選配 `barrelOffsetMm` 是筒尾到固定環中心的距離，缺少時沿用筒長的 70%。固定環寬 12 mm，兩端至少留半寬；改此值只移動筒身外形，不偷偷改最短安裝距離、孔位或機構姿態。
- 固定環沿用教師模型尺寸（耳距 28 mm）；可轉式與固定式外形完全相同（`syringeClampShape('pivot')` 與固定式相同），不再有另外的圓形轉軸座。鎖住的耳畫出螺絲，另一耳畫成空孔；底板孔留在 A 不隨方向移動。
- 安裝孔共用 `syringeClampFrameNodes`：固定式兩個、可轉式只在鎖住的那一耳開一個（圖層 SYRINGE_PIVOT，節點 `<id>_clamp_<lockedFoot>`），3D 與配件也只有這一顆螺絲。獨立固定板件加入對應材料孔；原有同心孔以 `mountIds` 建立衍生對應，保留原孔 ID 與孔徑，不疊切第二孔。超出輪廓、進入切槽或與其他孔重疊則回報幾何不可用。
- 保存、分享、一次確認復原與取消均沿用現有 snapshot 流程。預覽不改正式作品；切換不支援的連接會提示且停用確認。

## 介面與示範

安裝視窗最前方提供「固定安裝 · 雙孔鎖固」／「可轉安裝 · 固定環只鎖一顆螺絲」，可轉式另有「鎖哪一耳」（左耳／右耳，沿推進方向看；預設取能完整動作的一耳）。可轉式隱藏固定方向操作，由預覽顯示實際筒身角度；進階可調固定環距筒尾、針筒尺寸與套筒。H07 保留固定筒身與短桿，H08 使用同軸圓盤與只鎖一耳的同一個固定環、直接接工作孔。

## 驗收與誠實界限

測試涵蓋固定方向不變、可轉筒身隨行程改向、底板孔不動、配對孔數、同心孔不重複、圓盤與固定桿共用、筒身夾持位置邊界、欠約束拒絕、保存分享與舊檔相容。UI 驗證新增／調整、預覽取消與確認、復原、保存重開、手機及 3D。

幾何對位不代表夾牢。止滑、夾緊力、轉軸間隙、螺絲長度、承重、完整行程干涉均待實物核對。兩種新固定環安裝均維持既有加工輸出阻擋；不把一般鎖緊螺絲直接宣稱為合格旋轉軸。
