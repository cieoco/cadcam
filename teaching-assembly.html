第七單元・建議兩節，各 50 分鐘

升降夾爪組立

機構名詞卡：中間連桿在工具與部分舊圖中稱為「浮桿」。

這課的動作目標：讓兩個動作各司其職。

今天的任務

完成接合，依序操作：低位張開 → 收攏 → 升高 → 張開。

先備：完成四連桿與夾爪，平行保持原理在本頁先比較。保留原本機架、接點與其餘尺寸；完成基本任務後再做延伸。

開啟本課練習 ↗

複習四連桿與夾爪，整合兩個動作

先想一想：第一課雨刷改變輸出方向；本課平行四連桿讓工具架保持方向。第四課夾爪負責開合，第六課的剛性接合讓工具整組跟隨。

這課往前一步：先辨認平行保持，再完成接合與分軸控制；最後只換一項需求，自己決定修改方式並驗證。

先複習｜同樣四連桿，這次為什麼保持方向？

載入本課練習，先看升降臂：兩條臂等長 160 mm，機架與工具架孔距各 72 mm，非交叉組成平行四邊形。它仍有第一課的固定、輸入、中間與輸出關係，但對邊等長讓工具架保持方向。

  1. 先指出兩固定孔、驅動臂與活動工具架，再播放升降。比較第一課雨刷：雨刷輸出臂繞固定孔擺，這個工具架兩孔都在移動。
  2. 觀察工具架保持朝向，但孔走圓弧；需要垂直直線時，應回想第二、五課的滑軌／齒條。
  3. 先預測若只改一條臂會怎樣。用作品副本改一條、試看是否傾斜或出現求解問題，再復原；接合前核對回到兩臂等長。

檢查：能指出要把夾爪裝在活動工具架，而非固定機架。這次不再重畫四根桿，集中學會判斷輸出與接合。

1．把夾爪接到會動的工具架

開啟未接合練習，切到「組立」。升降臂與夾爪各有自己的機架底板；尚未接合時，夾爪不會跟著升降。完成後應是夾爪水平朝前、左右開合。不是把兩個機構平貼在同一面。

  1. 選「齒輪夾爪」，按「接合預覽」。第一步承接零件選升降臂的活動工具架，按下一步選安裝零件。安裝端會列出齒輪、夾指與底板；先辨認哪片在夾爪內保持固定，再點選「機架底板（建議）」才能按下一步。活動夾指也能點選查看，但目前不支援以它重設整個機構的固定基準。在「選承接面」確認「前面」，下一步到「選安裝面」確認「下面」，再到位置調整。可點面按鈕或 3D 外框選面；本課預選值仍可修改，「上一步」可返回。這是視窗的面名稱，最後仍要核對實際朝向。手機上方保留模型，下方選項可捲動；「放大預覽」可收起選項，再按「顯示選項」回來。橫放時模型與選項左右排列。
  2. 按一次 −90°，讓接合角度為 270°；點「左右」輸入 −60 mm。「上下」與「間距」保持 0 mm。旋轉讓夾爪朝前，偏移則留出角碼螺絲與齒輪的空間；這組數值只適用於本課範例。
  3. 核對預覽有兩顆角碼、夾爪水平朝前，再按「接上」。若有干涉提示先調整，選錯可取消。接上後看角碼與固定孔已確認，再逐軸試動。

夾爪底板是夾爪自己的機架；裝上後整片隨工具架移動，不代表它要固定在地面。

過關：播放 M1，夾爪整組跟工具架移動，沒有掉回原處；它接在活動工具架，不是固定機架。

找不到接合目標？

確認開的是本課「未接合練習」，且在組立選到齒輪夾爪。先以完整參考確認位置；不要任意刪除支架或改孔距。已接好的接合可用「拆下」重做。

2．播放模擬動作序列

  1. 接合完成後，在「組立」按「動作序列」。
  2. 先用預設六步：低位 → 張開 → 收攏 → 升高 → 張開 → 回低位。
  3. 按「驗證並播放」，觀察只有指定馬達改變角度，另一個保持。
  4. 只改第四步升高角度，再播放比較；按「停止並回位」可回到播放前姿態。

本課 M1 限 −40°～60°、M2 限 0°～30°，每步 0.5～5 秒。這是教學範圍；TT 馬達的模擬角度不代表實體可定位。播放前逐段取樣求解，播放完成會回位；按「保存序列」可隨作品 JSON 保存、重開與復原。也可依上圖手動切換馬達比較。

過關：接合保持，四步順序清楚，升降不自行改變開口。工具架保持方向，但走圓弧，不是垂直直線。

說給同學聽：如果把夾爪鎖在固定機架，哪一步會做不出來？

最後一關｜自己改需求，完成一次應用

保留已完成的組立。自己選一項需求：提高放置位置、改夾爪開合範圍，或調整搬運順序。先說出目標值、要改哪個零件／馬達，以及怎樣判斷達成，再動手；不用重新做完整七課。

  1. 先單獨驗證改過的機構，再回組立分軸試動。改高位時查升降角度與路徑；改開口時查夾指姿態；改順序時查每一步該動哪個馬達。
  2. 比較改前與改後，確認另一個動作沒有被破壞。出錯先讀診斷，依前六課查固定、接孔、尺寸、驅動與範圍，必要時復原。
  3. 保存 JSON、重開核對接合與動作，匯出影片作證據。自學不需 Classroom 帳號；班級另依老師規定交件。

完成標準：能解釋固定／輸入／輸出、選擇該改的參數、獨立修正一次問題，並拿出可重開的作品。動畫不驗證抓得牢、摩擦、承載或實際馬達出力；製作前還須核對板厚、孔位、軸長、支承及加工條件。

完成後：交一段作品影片

在「動作序列」按「匯出序列 MP4」。系統重新驗證後產生完整組立影片，附六步角度、總時間、版本與取樣求解結果。先預覽確認機構完整入鏡，再下載。若瀏覽器不支援 MP4，才使用裝置螢幕錄影。

先儲存 JSON、重開並試播，再預覽影片。自學保留兩者；課堂作業才回 Google Classroom 附加影片並繳交，不需另填學習單。

把第四課自己的夾爪換進來：模組與輸出端

這是同一課的替換應用；先保存內建接口作品。自建版本可直接從設計中的零件選接合端，目前承接支援連桿、板件、齒條及機架底板；安裝端須為自身固定板／底板。側面方向依板件外框定義，仍須核對實際材料與五金，不代表任意曲面都能鎖固。

  1. 開啟第四課自己的夾爪，選零件按「存成模組」，命名後「存到我的模組庫」，另存 JSON。模組庫只在目前瀏覽器，不是雲端備份。
  2. 重開本課作品，使用「新增 → 加入模組（保留作品）」加入自己的夾爪；不要再次開另一份 JSON 覆蓋組立。
  3. 在組立清單選要安裝的夾爪設計，按「接合預覽」。先選承接設計，再點實際承接零件；不用先「設為輸出端」。安裝端列出全部零件；點選可高亮及查看支援原因。底板只作建議，不自動確認；目前能繼續接合的是自身固定桿／底板。
  4. 依序選承接面、安裝面，再調位置、方向與間距。清單預選不限制其他零件；改選後核對預覽及「承接／安裝」名稱。確認接合才保存跟隨關係，取消不改作品。
  5. 從設計清單將需要的設計加入組立，核對底座與馬達 ID，再逐軸試動、保存重開。自建版本先手動驗證，不直接套用原課程的六步角度與馬達編號。

若沒有跟著升降，查是否真的安裝到活動輸出，而非只有加入分頁；有干涉就定位回設計修改，換層後仍要確認軸長與支承。

教師備課：節奏、答案與驗收

建議兩節：第一節 10 分鐘示範模組、20 分鐘接合、10 分鐘追隨驗收、10 分鐘保存備份。第二節 10 分鐘複習兩馬達、20 分鐘比較動作序列、10 分鐘螢幕錄影繳交、10 分鐘分享。沒有裝置錄影權限時先由教師確認校方允許的錄影方式，不把學生困在交件工具。

先備：四連桿保持姿態與第四單元夾爪。主臂長 160 mm、固定支點與工具架孔距各 72 mm；M1 的原教學範圍 −40°～60°。內建接合為工具架前面與夾爪底板下面、270°、左右 −60 mm，兩顆角碼固定；夾爪水平向前。課堂查看接合與馬達分工；影片驗收四步即可，不要求額外報告。

動作序列可保存與匯出組立 MP4；影片取樣求解通過不代表完成真實抓取。本課不要求真的搬運物體；物件抓取、摩擦、承載、馬達扭矩未驗證。檢視系統干涉提示，沒有提示也不等於完整機械安全驗證。

提早完成？只加一個挑戰

保持接合與尺寸不變，改成「低位收攏 → 升高 → 張開 → 降回」。先說出每一步該動哪個馬達，再操作。順序確認後回本頁「最後一關」，把這個順序變更當作自己的需求並驗證。
